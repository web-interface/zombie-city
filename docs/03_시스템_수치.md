### 연출 (문서 14 §2-7)
- 무기 연출·무기 장판·투사체는 **밤 어둠을 받지 않는 빛 층**(CanvasLayer 1)에 그린다 — 어둠에 묻혀 칙칙한 보라색이 되던 것을 또렷하게.
- 번개 = 지그재그 하얀 선 + 파란 테두리, 물줄기 = 굵은 파란 선 + 물방울, 불 = 주황 장판 + 떠오르는 불씨, 충격파 = 넓어지는 점선 고리 두 겹, 폭발 = 하얗게→주황→빨강 원 + 파편 + 연기 + 흔들림, 연기 구름 = 옅은 회녹색 뭉게(좀비가 비쳐 보이게).
- 진화 무기 = 금색(탄·테두리·고리·장판 가장자리), 흔들림 1.5배. 무기 칸 아이콘에 금색 테두리.
- 독·불처럼 계속 들어오는 피해는 좀비를 하얗게 번쩍이지 않는다 (독 걸린 좀비가 늘 보라색 덩어리로 보이던 것 고침).

## 5. 레벨과 경험치
- 다음 레벨까지 필요한 백신 조각: **기본 2 + 3.7 × 현재 레벨** (처음 계획 5 × 레벨 → 디자인 조사로 2 + 3 × 레벨(세지는 맛이 마지막 30초에 몰려서, 문서 13) → 밸런스 1~4차에서 2.5 → 3.2 → 3.7)
- 목표: **레벨 10 ≈ 1:30(1차 전직), 레벨 20 ≈ 3:30(각성)**, 5분 탈출 시 레벨 28~35, 진화 1~2개

| 버려진 차 | 체력 60 → 불붙고 3초 뒤 폭발 반경 30·피해 50 (생존자는 절반) |
| 기름통 | 체력 20 → 폭발 반경 18·피해 30 + 불 장판 4초 |
| 바리케이드 | 체력 150, 좀비가 닿으면 초당 10씩 부숨 |

## 10. 감염도 0~10
이기면 다음 단계가 열린다. 단계마다 **고철 +15%**.
| 단계 | 더해지는 규칙 |
|---|---|
| 1 | 좀비 체력 +20% |
| 2 | 특수 좀비 30초 일찍 |
| 3 | 보급 상자 1번만 |
| 4 | 좀비 속도 +10% |
| 5 | 보스 체력 +40% |
| 6 | 정전이 꼭 1번 |
| 7 | 회복 효과 −50% |
| 8 | 좀비 수 +25% |
| 9 | 다시 뽑기 0번 |
| 10 | 헬기가 5:20에 떠남 + 모든 좀비 체력 +50% |

## 11. 보상과 은신처
### 고철
| 한 일 | 고철 |
|---|---|
| 좀비 처치 | 100마리당 10 |
| 보스 처치 | 25 |
| 탈출 성공 | 60 |
| 생존자 같이 탈출 | 50 |
| 레벨 업 건너뛰기 | 3 |
- 최종 고철 × (1 + 0.15 × 감염도)
- 대략: 탈출한 판 250 안팎, 3분에 진 판 80 안팎

### 시설 6종 (각 5단계, 비용: 100 · 250 · 500 · 900 · 1500)
| 시설 | 단계마다 |
|---|---|
| 무기고 | 설계도로 해금한 무기가 판에 나옴 + 단계마다 시작 무기 1단계 높게(최대 +2) |
| 의무실 | 최대 체력 +10 |
| 작업대 | 다시 뽑기 +1, 3단계부터 빼 버리기 +1 |
| 발전기 | 손전등 반경 +6% |
| 무전실 | 보급 상자 내용 좋아짐, **3단계: 부활 1번** |

- 전부 최대까지 약 19,500 고철 → 탈출 80판 안팎 (오래 즐길 거리)
