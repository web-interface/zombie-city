# 5. 화면과 UI (고도화판 — 2026-11-07)

게임 화면은 180 × 320 픽셀 해상도를 폰에 정수배로 키운다. 글자·버튼도 같은 해상도 안에서 **픽셀 글꼴(Galmuri11·Galmuri9)과 각진 테두리**로 그려 스타일을 하나로 통일한다.
- **전직 창**(레벨 10): 갈래 카드 3장(바뀐 옷차림 미리보기·이름·효과) / 레벨 20: "각성!" 강조 연출
폰 비율이 달라도 잘리지 않고 넓어지게 한다.

## 게임 화면 배치
```
┌──────────────────────────┐
│████████ 경험치 막대 ██████│  ← 맨 위 가로 전체
│ Lv 7    🚁 03:12    처치 85│  ← 구조까지 남은 시간 가운데
│ [권][산][드][ ]  [조][운][ ][ ]│ ← 무기 4칸 · 장비 4칸 작은 아이콘
│                     (II) │  ← 일시정지
│     거대 변종 등장!        │  ← 알림 (2초)
│                          │
│           🧍 ← 생존자      │  ← 항상 화면 가운데
│          ▬▬  체력 막대     │
│                    ↗ 착륙 │  ← 4:30부터 화면 끝 방향 화살표
│                          │
│     ( ◯ ) 조이스틱    ( ★ )│  ← 왼쪽: 누른 곳에 조이스틱 / 오른쪽 아래: 스킬 버튼
└──────────────────────────┘
```
- 스킬 버튼: 지름 약 18% 화면 폭, 다시 쓸 수 있을 때까지 테두리가 시계 방향으로 차오름, 준비되면 반짝
- 스킬 버튼 주변을 누르면 조이스틱이 생기지 않음

## 원칙
- 버튼은 **엄지가 닿게 크게**, 화면 아래쪽에 모은다
- 글자는 짧고 쉬운 말 (예: "물렸어요…", "구조 성공!", "하나를 골라요")
- 숫자는 바뀔 때 살짝 튀어 오름 (고철·처치 수)
- 화면 위쪽은 폰 카메라 구멍에 가릴 수 있으니 **안전 영역 안에** 둔다
- 색: 밤의 아스팔트(짙은 회청색), 생존자 옷 색, 백신 조각 초록, 위험 빨강, 좀비 탁한 녹색·회색 — 자세한 건 [06](06_아트_사운드.md)
