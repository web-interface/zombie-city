# 5. 화면과 UI (고도화판 — 2026-11-07)

게임 화면은 180 × 320 픽셀 해상도를 폰에 정수배로 키운다. 글자·버튼도 같은 해상도 안에서 **픽셀 글꼴(Galmuri11·Galmuri9)과 각진 테두리**로 그려 스타일을 하나로 통일한다.
- **전직 창**(레벨 10): 갈래 카드 3장(바뀐 옷차림 미리보기·이름·효과) / 레벨 20: "각성!" 강조 연출
폰 비율이 달라도 잘리지 않고 넓어지게 한다.

### 묶음 3 화면 (2026-11-07 — 지금 만든 모양)
| 화면 | 내용 |
|---|---|
| 타이틀 | 밤거리 연출 그대로 + 큰 [출동!] · [은신처]·[오늘의 도전] · [도감]·[업적]·[설정], 맨 아래 가진 고철·최고 버틴 밤. 강화할 고철이 있으면 [은신처], 오늘 도전을 안 했으면 [오늘의 도전]이 깜빡임 |
| 생존자 고르기 | 왼쪽 위 [◀ 뒤로], 미리보기 아래 내 기록(최고 밤·처치·연속), 잠긴 생존자는 검은 실루엣 + 조건 + "지금 처치 4,680 / 5,000", 얼굴 칸 아래 줄 위에 감염도 줄 `[◀] 감염도 3 [▶] 고철 +45%` + 그 단계 규칙 한 줄 |
| 결과 | 큰 "버틴 밤 2" + "셋째 밤 1:12 · 도살자 돌진에 당함", 처치·레벨·최대 연속·고철 숫자 줄, 아래 목록(해금·감염도·새 기록·업적 띠가 하나씩 날아옴 → 주황 '아까운 표시' → 판 목표 ○× → 고철 항목별), 맨 아래 아주 큰 [바로 다시] + [생존자 고르기]·[은신처] |
| 은신처 | 옛 소방서. 줄마다 이름·■□ 단계·"최대 체력 +14 → +22"·한 줄 이야기·[가격] 버튼. 사면 금빛 번쩍, 모자라면 줄이 흔들리고 고철 숫자가 빨개짐 |
| 도감 | [좀비][무기][진화][히든 스킬] 칸(항목 있는 칸만), 3줄 격자, 만난 것은 그림(좀비는 걸음)·이름, 못 만난 것은 실루엣·??? , 위 줄에 전체 % |
| 업적 | 40줄: 묶음·이름·조건·보상 고철, 이룬 것은 금빛 + 이룬 날, 숨은 업적은 ??? |
| 오늘의 도전 (겹친 창) | 날짜, 오늘의 생존자(걸음), 규칙(빨강) + 설명, 오늘 최고 기록, [닫기]·[도전!] |
| 설정 (겹친 창) | 효과음·음악 [-] 10칸 막대 [+], 진동·화면 흔들림 [켜짐/꺼짐], 닫기. 멈춤 메뉴의 [설정]으로도 열림 |
- 목록 화면은 아래로 끌어 올려 넘긴다(얇은 각진 막대). 폰의 뒤로 가기 = [◀ 뒤로]. 버튼은 누르면 소리 + 살짝 눌렸다 돌아옴.

## 게임 화면 배치
```
┌──────────────────────────┐
│████████ 경험치 막대 ██████│  ← 맨 위 가로 전체
│ Lv 7    🚁 03:12    처치 85│  ← 구조까지 남은 시간 가운데
│ [권][산][드][ ]  [조][운][ ][ ]│ ← 무기 4칸 · 장비 4칸 작은 아이콘
│                     (II) │  ← 일시정지
│     거대 변종 등장!        │  ← 알림 (2초)
│                          │
│           🧍 ← 생존자      │  ← 항상 화면 가운데
│          ▬▬  체력 막대     │
│                    ↗ 착륙 │  ← 4:30부터 화면 끝 방향 화살표
│                          │
│     ( ◯ ) 조이스틱    ( ★ )│  ← 왼쪽: 누른 곳에 조이스틱 / 오른쪽 아래: 스킬 버튼
└──────────────────────────┘
```
- 스킬 버튼: 지름 약 18% 화면 폭, 다시 쓸 수 있을 때까지 테두리가 시계 방향으로 차오름, 준비되면 반짝
- 스킬 버튼 주변을 누르면 조이스틱이 생기지 않음

## 원칙
- 버튼은 **엄지가 닿게 크게**, 화면 아래쪽에 모은다
- 글자는 짧고 쉬운 말 (예: "물렸어요…", "구조 성공!", "하나를 골라요")
- 숫자는 바뀔 때 살짝 튀어 오름 (고철·처치 수)
- 화면 위쪽은 폰 카메라 구멍에 가릴 수 있으니 **안전 영역 안에** 둔다
- 색: 밤의 아스팔트(짙은 회청색), 생존자 옷 색, 백신 조각 초록, 위험 빨강, 좀비 탁한 녹색·회색 — 자세한 건 [06](06_아트_사운드.md)
