# 14. 전부 넣기 설계 — 시중 게임 기본 요소 (2026-11-07 아침)
> 사용자: "다음 라운드가 없다, 너무 쉽다, **1라운드조차 어렵게, 한 판 3분(5분은 루즈)**, 미친 듯이 중독성 있게·깨고 싶게, 새 좀비 많이, 캐릭터마다 무기·기술·레벨업 카드 다르게, 히든 스킬 아주 가끔, 한 판 하고 질린다, 눈에 확 띄는 무기 — 시중 게임처럼 모든 요소 다 넣어라". 이 문서가 묶음 1~3 의 기준(이름·ID·규칙·처음 숫자)이다. 숫자는 처음 값이고 난이도 테스터가 조정한다.

## 1. 끝없는 밤 (묶음 1)
### 1-1. 밤 이어가기
- **한 밤 = 3분** (사용자 "5분은 루즈"): 0:45·1:35·2:15 보스, 2:30 착륙 지점, 3:00 헬기, 6초 버티기, 3:25 헬기 떠남. 처음 10초부터 바로 몰려옴(빈 시간 없음).
- 성장도 3분에 맞춰 빠르게: 레벨 10(전직) ≈ 0:55, 레벨 20(각성) ≈ 2:10, 첫 1분 레벨 업 4~7초마다.
- 헬기를 타면 결과 화면 대신 **"첫째 밤 생존!"** 창: 이번 밤 처치·시간, 보상 = **체력 50% 회복 + 카드 한 장 더** → [다음 밤으로]. 무기·장비·레벨·전직은 그대로.
- 다음 밤: 좀비·조각·구급함·장판·투사체를 비우고 시간 0:00 부터. 위 표시줄 "둘째 밤 · 구조까지".
- 판이 끝나는 때: 쓰러짐 · 헬기 놓침 · 포기. 결과 = **버틴 밤 수**(+ 마지막 밤 몇 분), 처치, 레벨.
- 세지는 정도 (`data/run_rules.json` `nights`):
| 항목 | 규칙 (N = 몇째 밤) |
|---|---|
| 좀비 체력 | 시간 성장을 밤 사이에도 이어 감: `1 + 0.09 × (경과 + 180 × (N−1))` (사용자 '시간이 갈수록 체력 늘고 안 죽게') |
| 나오는 수 | × (1 + 0.25 × (N−1)) |
| 닿는 피해 | × (1 + 0.20 × (N−1)) |
| 빠르기 | × min(1 + 0.05 × (N−1), 1.3) |
| 보스 체력 | × (1 + 10 × (N−1)) (처음 값, 테스터가 맞춤) |
| 정예 확률 | 0.6% + 0.4% × (N−1) |
- 목표(**개고수 기준 — 사용자 '다들 개고수라고 생각하고 진짜 빡세게'**): 고수 봇 첫째 밤 40~55%, 둘째 15~25%, 셋째 5~10% / 보통 봇 첫째 밤 10~20% / 초보 봇 0~5%. 어렵되 억울하지 않게(모든 큰 공격 예고), 쓰러지는 때가 한 구간에 몰리지 않게.

## 2. 나만의 빌드 (묶음 2)
### 2-1. 카드 고르는 규칙
- 레벨 업 카드는 **그 생존자의 전용 무기 4개(시작 무기 포함) + 전용 장비 1개 + 공용(무기 3·장비 12)** 에서만 나온다. 다른 생존자 전용 무기는 안 나옴.
- 무기 4칸·장비 4칸 (지금 그대로). 무기가 최고 단계 + 짝 장비가 있으면 다음 상자(또는 레벨 업)에서 **진화**.
- **빼 버리기**: 판마다 2번, 고른 카드를 그 판에서 다시 안 나오게.
- **히든 스킬 카드**: 레벨 8 이후 레벨 업마다 **2%**, 한 판에 한 번. 금색 반짝이 카드 + 전용 소리. 고르면 스킬 버튼이 히든 스킬로 바뀜(전직이 바꾼 스킬보다 우선).

### 2-6. 보물 상자·필드 줍기
- **보물 상자**: 보스·정예가 떨굼. 열면 슬롯이 돌다 멈춤 — 강화 1개(70%)·3개(25%)·5개(5%, 금빛 폭죽). 진화할 수 있는 무기가 있으면 진화가 먼저.
- **줍기 3종** (좀비가 아주 가끔, 정예는 꼭 1개): `magnet` 자석(화면 조각 다 끌어옴, 0.15%) · `bomb` 폭탄(화면 좀비 큰 피해, 0.08%) · `freeze` 냉각 스프레이(좀비 5초 멈춤, 0.08%)

### 2-7. 눈에 띄는 연출 (사용자 "눈에 확 띌 만한 무기")
- 무기마다 모양이 다름: 번개(지그재그 선, 하얀 번쩍), 물줄기(파란 굵은 선 + 물방울), 불(주황 장판 + 불씨), 충격파(넓어지는 고리), 폭발(원 + 파편 + 흔들림).
- 진화 무기 = 금색 테두리·더 큰 효과·전용 소리, 진화 순간 "진화!" 띠 + 느린 화면.
- 히든 스킬 = 컷인 + 화면 번쩍 + 큰 흔들림.

## 4. 중독 설계 — "한 판만 더" (사용자 "미친 듯이 중독성 있게, 깨고 싶게")
| 장치 | 내용 | 묶음 |
|---|---|---|
| 짧은 판 + 이어지는 밤 | 3분이라 부담 없고, 헬기 타면 바로 "다음 밤?" — 멈출 틈이 없게 | 1 |
| 쉴 새 없는 보상 | 4~7초마다 레벨 업, 정예·보스 상자 슬롯, 금색 히든 카드, 진화 순간 연출 | 1·2 |
| 연속 처치 | 화면 위 "연속 147!" 숫자가 커지고, 50·100·200 마다 소리·빛 + 조각 보너스. 맞으면 끊김 | 1 |
| 아까운 표시 (결과 화면) | "최고 기록까지 1밤!", "야구선수 해금까지 처치 320", "진화까지 장비 하나 부족했어요" — 바로 [다시 하기] 큰 버튼 | 1·3 |
| 판마다 작은 목표 3개 | "정예 3마리", "체력 30% 밑에서 보스 처치", "카드 건너뛰기 없이 둘째 밤" → 고철 보너스 | 3 |
| 쌓이는 성장 | 고철 → 은신처 강화, 생존자·무기 해금으로 카드가 점점 늘어남(새 것이 계속 나옴) | 3 |
| 모으기 | 도감 %·업적·생존자별 최고 밤 — 빈칸이 보이게 | 3 |
| 매일 할 이유 | 오늘의 도전(하루 한 판 같은 조건) + 기록 | 3 |
| 공정한 어려움 | 어렵지만 억울하지 않게: 모든 큰 공격은 예고, 쓰러진 이유 표시 — "내가 실수했다 → 다시" | 1 |

## 5. 지키는 것
- 숫자는 `data/*.json` 에만, 파일 머리말 4칸, 코드 지도(11) 같은 작업에서 고침, 함수 40줄·파일 300줄 (넘으면 나눔).
- 실제 브랜드·실명 없음(동네 말투 이름만).
- 묶음 끝: 검수관(경고 0·머리말 검사) + 난이도 테스터(위 목표) → 웹 공개.
