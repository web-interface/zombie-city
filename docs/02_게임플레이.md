# 2. 게임플레이 (고도화판 — 2026-11-07)

> 목표: **"한 판만 더"**를 부르는 고급 생존 액션.
> 한 판은 5분으로 짧게 하되, 판마다 다른 조합이 나오고, 판이 끝나도 쌓이는 게 있어야 한다.
> 숫자는 [03_시스템_수치.md](03_시스템_수치.md), 이름·설정은 [04_콘텐츠_주제.md](04_콘텐츠_주제.md).

## 1. 게임 한 바퀴 (전체 흐름)
```
앱 켜기 → 타이틀 → [은신처] ─────────────────────────────┐
                      │                                    │
                      ▼                                    │
               [출동 준비]                                 │
        지역 고르기 · 생존자 고르기 · 감염도 고르기        │
                      │                                    │
                      ▼                                    │
               [한 판 · 5분]                               │
     움직이기 → 자동 공격 → 백신 조각 → 레벨 업 3택1       │
     이벤트 · 보스 · 진화 → 4:30 헬기 신호 → 탈출          │
                      │                                    │
                      ▼                                    │
               [결과 화면]                                 │
     고철·설계도·숙련도 보상, 새 기록, 해금 알림 ──────────┘
                (은신처에서 시설 짓고 다시 출동)
```

## 2. 조작
| | 방법 |
|---|---|
| 이동 | 화면 **아무 데나 누르고 끌기** (누른 곳이 조이스틱 중심) |
| 공격 | **자동** — 무기마다 목표 찾는 방식이 다름(가까운 적, 앞쪽, 무작위 등) |
| 스킬 | 오른쪽 아래 **스킬 버튼**. 다시 쓸 수 있을 때까지 테두리가 차오름 |
| 일시정지 | 오른쪽 위 버튼. 앱을 나가면 자동으로 멈춤 |
| PC 시험용 | 마우스 드래그·WASD 이동, 스페이스 = 스킬 |

- 한 손(엄지)으로 이동하고, 같은 손이나 다른 손으로 스킬을 누를 수 있게 버튼은 엄지가 닿는 곳에 둔다.

## 3. 한 밤 시간표 (3분 · 끝없는 밤 — 2026-11-07 아침 바꿈, 문서 14 §1)
> 사용자: "5분은 루즈해, 3분으로", "1라운드조차 어렵게", "5분 지나면 다음 라운드로 가야지". 헬기를 타면 판이 끝나지 않고 **다음 밤**으로 이어진다.

> **2026-11-07 저녁 재설계(문서 15 §3 → 16 §4)로 바꿈** — 정본은 `data/spawn_curve.json` (minimum_segments·night_score).

| 시간 | 박자 | 필드 최소 좀비 | 무슨 일 |
|---|---|---|---|
| 0:00–0:30 | 몸풀기 | 12 → 25 | 첫 레벨 업 6초 안, 첫째 밤 첫 30초는 좀비 체력 ×0.7 |
| 0:30–0:55 | 쌓기 | 25 → 45 | |
| 0:55 (창 ~1:10) | **몰아치기 ①** | 70 | 한쪽에서 떼 돌진 (빨간 화살표 예고 1.5초) — 둘째 밤은 포위, 그 뒤 번갈아 |
| 1:10–1:20 | 숨 돌리기 | 20 | 새 무리·특수 좀비 없음 |
| 1:15 (창 ~1:25) | **정예** | 20 | 금빛 정예 1마리 → 보물 상자. 창을 놓치면 버리고 상자는 착륙 지점 보급 상자로 |
| 1:25–1:35 | 쌓기 | 40 → 60 | |
| 1:35 (창 ~1:45) | **보스** | 15 | 밤마다 1마리(도살자 → 철거반장 → 거대 감염체 차례로) → 보물 상자. 정예가 살아 있으면 정예는 상자 없이 달아남 |
| 보스 처치 ~ 2:30 | 진화 뒤 몰아치기 | 110 | 보스가 2:30 넘게 살면 건너뜀 |
| 2:30 | 착륙 지점 (기준점) | 140 | 착륙 지점 화살표, 헬기 곡 |
| 2:50 | 마지막 몰아치기 (기준점) | 140 | 착륙 지점 반대쪽에서 떼, 보스가 살아 있으면 절반 |
| 3:00 | 헬기 도착 (기준점) | 140 | 착륙 원 안에서 6초 버티면 그 밤 생존 (3:25 에 떠남). 보스를 두고 가면 상자 없음(알림) |

- **최소 마릿수**: 필드 좀비가 최소보다 적으면 빠르게 채우고, 많으면 조금씩만 더 나온다. 화면 바로 바깥에서, 가는 쪽 앞에서 더 자주.
- **큰 일은 하나씩**: 몰아치기·정예·보스·들개 무리(둘째 밤부터 0:38)는 정해진 '창' 안에서만, 서로 15초 넘게. 다른 큰 일이 진행 중이라 창을 놓치면 미루지 않고 버린다(보스는 안 버림). 정예·보스가 주인공일 땐 최소 좀비가 절반 아래로. 화면 위 시간 줄에 주황 = 몰아치기, 금색 = 정예, 빨강 = 보스, 헬기를 미리 보여 주고, 5초 전엔 그 표시가 깜빡이며 짧은 경보가 울린다.
- **좀비 체력**: 한 밤 안에서는 최대 +30% 만. 어려움은 마릿수·박자로.

- **밤마다 세진다** (문서 16 §2): 일반 좀비 체력 밤마다 +0.30배·보스 +0.5배(직선), 최소 좀비 +3%(최대 ×1.9), 닿으면 피해 +3%, 빠르기 +5%(최대 1.3배), 정예 자리는 9밤마다 하나 더.
- **밤마다 새 얼굴**: 둘째 밤 진압복·비명·들개 무리 + 보스 철거반장, 셋째 밤 덩치 + 보스 거대 감염체. 넷째 밤부터는 셋째 밤 구성이 더 세게.
- **음악도 밤마다 바뀐다** (첫째·둘째·셋째·넷째 밤 이후 곡), 보스가 나오면 보스 곡, 분노하면 더 격한 곡, 착륙 지점이 뜨면 헬기 곡.

### 공정함 규칙 (2026-11-07 밤 추가)
- **한 번에 생존자를 무는 좀비는 3마리까지**(보스는 따로) — 둘러싸여도 1~2초 만에 끝나지 않고 빠져나갈 틈이 있다 (억울한 죽음 금지)
- **편의점 구급함**: 쓰러진 좀비가 가끔 떨군다. 주우면 체력 20% 회복 — 위기에서 돌아올 길
- 헬기 버티기·보스 돌진 중에는 카드 창을 미룬다 (흐름 끊지 않게)
- 판이 끝나면 결과 화면에 이유가 나온다: "○○에게 당함" / "도살자 돌진에 당함" / "헬기가 떠날 때까지 착륙 지점에 못 탔어요"
- 보스의 모든 기술은 먼저 보인다: 빨간 예고선(돌진)·예고 원(해머·산성 비·폭발)·예고 띠(땅 가르기·토하기), 날아오는 식칼·철근도 보인다

## 4. 빛과 어둠 (이 게임만의 규칙)
- 밤이라 화면은 어둡고, **생존자 손전등**과 **가로등·조명탄·불** 주변만 밝다.
- **어둠 속 좀비**: 조금 더 빠르다. 기어다니는 좀비는 어둠에서 아예 안 보인다.
- **빛 안의 좀비**: 느려지고, 받는 피해가 늘어난다.
- 그래서 "어디서 싸울지"가 전략이 된다: 가로등 아래로 끌어들이기, 발전기 켜기, 조명탄·손전등 빌드.
- 정전 이벤트 때는 가로등이 꺼져서 손전등만 남는다 → 진짜 위기.

## 5. 성장과 조합 (빌드)
### 무기와 장비
- **무기 칸 4개, 장비 칸 4개.** 시작 무기 1개는 생존자마다 다르다.
- 레벨 업마다 **3장 중 1장**: 새 무기 / 가진 무기 강화 / 새 장비 / 가진 장비 강화
- 무기·장비는 각각 **최대 5단계**
- 칸이 다 차면 가진 것만 강화된다 → **무엇으로 칸을 채울지**가 첫 번째 고민

### 진화 (조합의 꽃)
- **무기 5단계 + 짝이 되는 장비(1단계 이상)** → 다음 **보스 상자**를 열 때 그 무기가 **진화**한다.
- 진화 무기는 모양·소리·효과가 확 바뀐다 (짧은 강조 연출).
- 무기 12종 모두 진화형이 있다 → 짝을 아는 것 자체가 실력이 된다 (도감에 기록).

### 전직 (생존자 갈래 고르기 — 2026-11-07 추가, v0.1부터)
- **레벨 10 → 1차 전직**: 그 생존자의 **갈래 3개 중 1개**를 고른다. 스킬·특성이 바뀌고 **옷차림이 바뀐다**.
- **레벨 20 → 2차 전직(각성)**: 고른 갈래가 한 번 더 강해진다 (자동, 강조 연출).
- 같은 생존자라도 갈래에 따라 플레이가 달라짐 → 생존자 6 × 갈래 3 = **18가지 길**.
- 갈래 이름·효과는 [03 §1-2](03_시스템_수치.md), 모습은 [04 §2](04_콘텐츠_주제.md).
- 시험판에서는 3갈래 모두 열림. 은신처가 생기면(v0.5) 세 번째 갈래는 숙련도 5에서 열리게 바꾼다.

### 뽑기 조절

|---|---|---|
| 다시 뽑기 | 3장을 새로 뽑음 | 1 |

| 건너뛰기 | 안 고르고 고철 조금 받기 | 무제한 |

## 6. 좀비와 보스
- **일반 4종**: 숫자로 밀어붙이는 기본 좀비 (걷는, 달리는, 방호복, 기어다니는)
- **특수 5종**: 행동이 다름 (침 뱉기, 터지기, 무리 돌진, 비명으로 주변 강화, 방패로 총알 막기) → 무기 조합에 따라 상대하기 쉬운 좀비가 다름
- **보스 6종**: 지역마다 3마리, 저마다 공격 방식이 있고 **공격 전에 예고**(빨간 선·원)를 보여 줌 → 피하는 실력이 통함
- 보스를 쓰러뜨리면 **보스 상자**: 진화 또는 무기·장비 여러 단계 한 번에

## 7. 이벤트
판마다 지역 이벤트 묶음에서 **1~2개**가 무작위로 일어난다.
| 이벤트 | 내용 | 선택 |
|---|---|---|
| 보급 상자 | 헬기가 상자를 떨굼. 회복·폭탄·자석·강화·설계도 | 위험한 곳까지 갈지 |
| 포위 | 사방에서 좀비가 고리 모양으로 조여옴 | 뚫을 방향 고르기 |
| 정전 | 20초 동안 가로등이 꺼짐 | 손전등에 의지 |
| 발전기 | 지도에 2곳 표시, 3초 서 있으면 주변 가로등이 켜지고 빛이 넓어짐 | 좀비 사이로 갈지 |
| 생존자 구출 | 숨은 생존자를 찾아가면 40초 같이 싸워 줌, 같이 탈출하면 고철 보너스 | 시간 써서 갈지 |
| (지역 전용) | 지하철 열차 통과, 마트 셔터·카트, 옥상 산성비 등 | |

## 8. 지형
- **버려진 차**: 쏘면 불붙다가 폭발 (주변 좀비 큰 피해, 연쇄 폭발 가능). 생존자도 가까우면 다침.
- **기름통**: 작은 폭발 + 불 장판
- **바리케이드**: 좀비가 부술 때까지 길을 막음
- 지역마다 전용 지형이 있다 (04).

## 9. 승패와 보상
- **밤 생존**: 착륙 지점에서 6초 버티기 → 다음 밤으로 (판은 계속). 기록 = **버틴 밤 수**
- **판 끝**: 체력 0, 3:25까지 못 탐(헬기 놓침), 포기
- **부활**: 은신처 무전실 3단계부터 한 판에 1번 (광고 없음)
- **결과 화면**: 버틴 시간, 처치 수, 최고 연속 처치, 진화한 무기, 받은 고철·설계도·숙련도, 새 기록 표시

## 10. 판 밖 성장 (은신처)
| 요소 | 내용 |
|---|---|
| **고철** | 판에서 얻는 기본 재화. 시설 짓기·강화에 씀 |
| **설계도** | 보스·보급 상자에서 드물게. **무기고**에서 새 무기를 판에 나오게 해금 |
| **시설 6종** | 무기고·의무실·작업대·발전기·무전실·훈련장 (각 5단계) |
| **생존자 해금** | 생존자 6명. 조건을 채우면 합류 (예: 지하철역 탈출) |
| **숙련도** | 생존자마다 1~10. 많이 쓸수록 스킬 강화·옷 색 해금 |

## 11. 여러 번 하게 만드는 장치 (다시 하기 설계)
| 장치 | 왜 다시 하나 |
|---|---|
| 무기 12 × 장비 10 × 진화 12 | 판마다 다른 조합, "이번엔 저 진화 해 봐야지" |
| 생존자 6명 | 시작 무기·특성·스킬이 달라서 같은 지역도 다르게 |
| 지역 4곳 | 지형·보스·이벤트가 다름 |
| 감염도 0~10 | 이기면 더 어려운 단계가 열림, 단계마다 보상 증가 |
| 은신처 성장 | 져도 고철이 쌓여서 다음 판이 조금 쉬워짐 |
| 숙련도 | 아끼는 생존자를 키우는 맛 |
| 오늘의 도전 | 하루 한 번, 모두 같은 조건(지역·생존자·규칙 고정) → 최고 기록 |
| 주간 변종 | 일주일마다 특별 규칙 (예: 좀비 2배·체력 2배) |
| 도감·업적 | 좀비 정보·진화 짝·업적 40개 모으기, 업적으로 옷 색 해금 |
| 기록 | 지역·생존자별 최고 기록, (나중) 온라인 순위표 |

## 12. 고급 게임 품질 기준
"싸 보이지 않게" 지킬 것. 단계마다 이 표로 점검한다.
- **반응**: 손 떼고 붙이는 순간 바로 움직임, 60fps 유지 (좀비 300마리에서도)
- **모든 것이 움직인다**: 걷기 4장 × 3방향, 공격·맞기·쓰러지기 동작, 대기 숨쉬기
- **손맛 3겹**: 화면(번쩍·흔들림·잠깐 멈춤) + 소리(맞는 소리 여러 개 무작위) + 진동
- **연출**: 시작 무전, 보스 등장 예고, 진화 강조, 헬기 서치라이트와 탈출 장면
- **음악**: 위험해질수록 악기가 더해지는 음악 (좀비 수·보스에 따라)
- **UI**: 픽셀 스타일 하나로 통일, 숫자는 튀어 오르는 애니메이션, 화면 전환 효과
- **첫 판 안내**: 글 설명 대신 처음 1분 동안 자연스럽게 알려 줌 ("끌어서 움직여요" → "버튼으로 스킬")
- **저장**: 판 끝날 때마다 저장, 앱이 꺼져도 은신처 진행은 안 날아감
