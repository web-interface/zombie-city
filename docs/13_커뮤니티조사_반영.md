# 13. 커뮤니티·디자인 조사와 반영 (2026-11-07)
> 해외 커뮤니티·국내 커뮤니티·게임 디자인 분석 조사 에이전트 3명이 모은 것을 요약하고, 무엇을 어디에 반영했는지 적은 문서. 사용자 요청: "미친 듯이 재밌게, 모든 커뮤니티 다 뒤져서 반영".

## 조사 범위

|---|---|---|

## 한 줄 결론
- 사람들이 빠지는 것: **짧은 판 + 떼로 몰려온 적을 쓸어버리는 맛 + 빌드가 '터지는' 순간 + 캐릭터마다 다른 손맛**
- 별점을 깎는 것: **안 보여서 죽음, 흐름 끊는 창, 노가다·과금·에너지·강제 광고, 이어하기 없음, 요소 과다**

## 반영한 것 (v0.1 코드·숫자에 이미 들어감)
| 조사 내용 | 반영 | 어디 |
|---|---|---|
| 세지는 맛이 마지막에 몰림 (5×레벨이면 5분에 Lv22, 2차 전직이 4:25) | 필요 경험치 **2 + 3×레벨** → Lv10 ≈ 1:30, Lv20 ≈ 3:30, 5분에 Lv28 | data/run_rules.json experience, level_up.gd |
| 몰아치기와 숨 돌리기의 파도 (L4D AI 감독) | 보스 잡으면 **18초 동안 좀비 40%만** | spawn_curve.json, zombie_spawner.gd |
| 마지막 1분이 너무 빽빽 | 마지막 보스 **4:00**, 헬기 버티기 중엔 **카드 창 안 띄움** | spawn_curve.json, run.gd |
| 손맛은 '중간'이 최고, 흔들림은 충격 값 제곱 | 흔들림 최대 3점·충격 값 제곱·초당 1.5 감소, 이름 붙인 충격(맞음 0.25·폭발 0.4·보스 처치 0.5) | run_rules.json juice, run_camera.gd |
| 잠깐 멈춤(히트스톱) | 보스 처치 0.15초 멈춤 + 0.6초 30% 느리게, 큰 피격 0.06초 | run_rules.json juice, run.gd |
| 후반 화면 과부하 | 내 투사체 살짝 투명, **보스 예고선은 맨 위**, 피해 숫자는 치명타·30 이상·보스만 최대 20개 | projectile_pool.gd, effects.gd, zombie_horde.gd |
| 뭐에 죽었는지 모름 | 결과 화면에 **"○○에게 당함"** | survivor.gd last_damage_source, run_recorder.gd |
| 어둠 속 안 보이는 적 (국내: 어두운 맵 비판) | 기어다니는 좀비도 흐린 윤곽 18%, 40점 안이면 45% | zombie_horde.gd |
| 같은 소리 반복 | 소리마다 변형 + 높낮이 ±8%, 같은 소리 0.035초 안 중복 금지, 조각 연달아 주우면 음이 올라감 | sound_player.gd, vaccine_shard_field.gd |
| 이어하기·중단 | 앱 나가면 바로 일시정지 | run.gd |
| 보스는 배우는 것 | 돌진 전 1초 빨간 선 깜빡임, 패턴 하나 | boss_director.gd |

## 한국적 재미 (국내 조사 → 04 콘텐츠에 반영 예정)
- 동네 디테일: 편의점·한글 간판·초록 시내버스·주황 택시·분리수거함 (틀리면 안 됨 — 사람들이 뜯어봄)
- 지명 패러디: '새벽역 3번 출구', '새벽 먹자골목'
- 알림을 **긴급재난문자 모양**으로 ("[새벽시청] 거대 변종 출몰. 외출 자제 바랍니다")

- 사망 화면·엘리트 좀비 이름에 뜬금 개그 한 줄 (억지 국뽕·신파는 금지)
