## 1. 이 게임이 주는 것 (재미 기둥 3개)
1. **3분마다 맨손에서 다시 강해지는 맛** — 밤마다 레벨 1부터, 새 조합을 짠다.
2. **읽히는 위험을 피하는 손맛** — 적의 공격은 늘 보이고, 피하면 산다. 모르고 죽는 일은 없다.
3. **30밤 동안 자라는 내 것** — 들고 다니는 무기 하나와 쌓이는 훈장, 구역마다 새 얼굴·보스, 30밤 엔딩.

"돈값" 체크(조사): 첫 1분 안에 첫 레벨 업 여러 번, 첫 밤 안에 첫 진화, 캐릭터마다 다른 손맛, 밤마다 새 것, 이어하기, 튕김 없음, 쌓인 재화는 쓸 곳이 있음.

## 2. 한 판 구조 — 30밤

```
[생존자 고르기] → 1밤 ─ 헬기 ─ [밤 생존: ① 들고 갈 무기 1개 ② 훈장 1장] → 2밤 → … → 30밤 → [엔딩]
                  └ 밤마다 레벨 1 · 무기/장비 비움 (들고 간 무기 1개만 남음, 레벨 그대로·진화는 풀림)
```
- **6구역 × 5밤.** 5·10·15·20·25밤 = 구역 보스 밤, 30밤 = 마지막 밤(마지막 보스 → 도시 탈출 엔딩·칭호).
- **이어하기**: 밤이 시작될 때마다 자동 저장. 앱을 꺼도 그 밤 처음부터 이어 한다 (한국 리뷰 "30분 연속은 힘들다, 이어하기 원함").
- **쓰러지면**: 그 밤 처음부터 **다시 하기 2번**(판마다). 다 쓰면 판 끝. 30밤 판이 90분을 넘으니 한 번 실수로 다 날리지 않게.
- **전직**(첫 레벨 10)·**히든 스킬**은 한 번 얻으면 판 끝까지. **각성**은 10밤 구역 보스를 잡으면.
- **다시 뽑기·빼 버리기** 횟수는 밤마다 다시 채움.

## 3. 한 밤(3분) 흐름 — 정해진 박자

### 3-1. 시간표 (뱀서식 '분 표' + L4D식 숨 돌리기)
| 시간 | 박자 | 화면 최소 좀비 | 무슨 일 |
|---|---|---|---|
| 0:00–0:30 | 몸풀기 | 12 → 25 | 레벨 업 4초마다. 그 밤의 새 얼굴이 0:20 에 처음 등장(이름 띠) |
| 0:30–1:00 | 쌓기 | 25 → 45 | 긴급 임무 등장(40초 안에) |
| 1:00–1:12 | **몰아치기 ①** | 70 | 한쪽에서 떼 (예고 화살표 1.5초) |
| 1:12–1:25 | 숨 돌리기 | 20 | 새 무리·특수 없음 |
| 1:25 | **정예** | (그대로 20) | 금빛 정예 1마리 → 보물 상자 |
| 1:30–1:55 | 쌓기 | 40 → 60 | |
| 2:00 | **보스** | 15 (보스와 1:1에 가깝게) | 보스 처치 → 보물 상자(여기서 첫 진화가 가장 흔함) |
| 보스 처치 뒤 | **진화 뒤 몰아치기** | 110 | 진화한 무기로 쓸어버리는 맛 — 대신 밀도가 확 오른다 (뱀서 10→11분) |
| 2:30 | 착륙 지점 | 140 | 마지막 몰아치기 |
| 3:00–3:06 | 헬기 버티기 | 140 | |
- **위 표는 '최소 마릿수'** 다. 그보다 적으면 빠르게 채운다(뱀서 방식). 너무 많이 죽이면 더 몰려오고, 못 죽이면 늘지 않는다 → 초반에 잘 못 죽여도 숨 막히지 않고, 세지면 바로 더 몰려옴.
- **큰 일은 하나씩**: 몰아치기·정예·보스·들개 무리는 서로 **15초** 넘게 떨어진 정해진 자리에만. 보스가 살아 있으면 다른 큰 일은 보스가 쓰러질 때까지(최대 25초) 미룬다. 정예는 한 번에 한 마리, **정예가 살아 있는 동안 일반 좀비 최소 마릿수는 절반 아래로**(정예가 그 자리의 주인공 — 브로테이토·뱀서·L4D). 정예 상자엔 진화 + 회복.
- **앞으로 올 일 보여 주기**(딥락): 위쪽 시간 줄에 작은 표시(금색 = 정예, 빨강 = 보스, 헬기 = 탈출). 겹쳐 오는 느낌이 '예고된 긴장'이 된다.
- 기존 **'제자리 압박' 알림·한 번에 무는 좀비 4·어둠 속 빨라짐은 뺀다** — 좀비가 진행 방향 앞에서도 나오고 최소 마릿수가 채워지면 가만히 서 있으면 자연히 둘러싸인다. 보이지 않는 규칙은 없앤다.

### 3-2. 한 밤 안에서 좀비 체력은 거의 그대로
- 일반 좀비 체력: 한 밤 안에서는 **최대 +30%** 만 (지금 17배 → 1.3배). 어려움은 **마릿수·새 얼굴·특수 좀비·박자**로.
- 이렇게 하면 초반에 무기 하나로도 '녹는' 맛이 나고(1구역은 맞으면 0.3초 안팎에 쓰러짐), 후반엔 진화 무기가 녹이는 만큼 **더 많이** 몰려와서 쉬어지지 않는다.

## 5. 성장 — 한 밤 안 / 30밤 동안

### 5-1. 한 밤 안 (레벨 1 → 17 안팎)
- 경험치 곡선은 뱀서처럼 **처음 빠르고 뒤로 갈수록 느리게**: 첫 1분 6번, 끝 1분 3번, 한 밤 약 16~18번.
- 칸: 무기 4 · 장비 4. 카드 약 17장으로는 **다 못 채운다**(무기 5단계 × 4 + 장비 × 4 = 40) → 고르는 게 중요해진다. 풀이 바닥나는 일 없음.
- **'회복'만 남는 문제 해결** (지금: 레벨 40~50 이면 칸이 다 차서 회복 카드만 나옴, 가장 많이 고른 카드 = 회복 2,323번): ① 밤마다 레벨 1부터라 한 밤 카드 17장 < 고를 거리 40 ② 늦은 밤엔 무기 최대 레벨이 올라가(§5-2) 고를 거리가 더 늘어남 ③ 그래도 다 차면 회복 대신 **한계 돌파 카드**(피해 +5%·공격 속도 +4%·범위 +6%·최대 체력 +8 — 그 밤 끝까지, 끝없이 쌓임) ④ 회복 카드는 체력이 50% 아래일 때만 한 장 끼어듦.
- 진화: 무기 5단계 + 짝 장비 + **보물 상자**(정예 1:25 · 보스 2:00 · 임무). 레벨 업 카드엔 진화 없음.
- 카드 줄 때 생존자 전용 무기가 더 자주(생존자마다 다른 손맛 — 브로테이토 칭찬 1위).

### 5-2. 30밤 동안
- **들고 가는 무기 1개**: 레벨 그대로, 진화는 풀림(그 밤에 짝 장비 + 상자로 다시 진화 → 밤마다 '진화!' 순간).
- **무기 레벨은 5 넘어서도 오름**: 그 밤 최대 레벨 = 5 + 2 × (밤 − 1) (30밤에 63). 6레벨부터 한 레벨마다 피해 +8%(5단계 값 기준 더하기), 5레벨마다 작은 보너스(범위 +5% / 관통 +1 / 발 수 +1 차례로, 발 수는 무기마다 상한).
- **새로 얻는 무기는 그 밤 최대 레벨의 절반에서 시작** (늦은 밤에도 새 무기가 쓸모 있게).
- **훈장**: 밤마다 3장 중 1장(안전 2 + 위험 1, 위험 = '나쁜 점 + 큰 좋은 점'). 같은 훈장은 3번까지 쌓임. 생존자 전용 훈장 2장씩(조금 더 자주). 목록은 부록 A.

## 7. 보이는 규칙 — 내 것과 적의 것 (사용자 지적 1순위)

### 7-1. 색 언어 (색 + 모양 둘 다 — 적록 색약 8~10% 배려)
| 무엇 | 색 | 모양 | 밝기 |
|---|---|---|---|
| **적 장판·웅덩이** | 주황빨강·자홍 계열 (산성도 초록 → **주황빨강+자홍 거품**으로 바꿈) | **안쪽 1점 밝은 테두리 + 바깥 1점 어두운 테두리 + 빗금**, 테두리 깜빡 | 스스로 빛남(밤·안개 영향 없음) |
| **적 예고** | 빨강 | 차오르는 원·선 | 스스로 빛남 |
| **적 투사체** | 빨강·자홍 | 검은 테두리 1점 | 밝게 |
| **내 장판·연기·불** | 하늘색·파랑·흰색 (**내 불은 파란 불·흰 불** — 주황빨강은 적 전용) | 테두리 없음 또는 점선, 빗금 없음 | 불투명도 25~40% |
| **내 투사체** | 흰색·노랑·하늘색 (빨강·자홍 금지) | 테두리 없음 | 보통 |
| 줍는 것 | 금색 | 통통 튐 | 반짝 |
| 내 위험 | 화면 가장자리 빨강 | | |
- **규칙: 내 무기에는 적 색(빨강·자홍·주황빨강)을 쓰지 않는다.** 새 무기를 만들 때 검사. 내 효과 입자 수에는 상한.

### 7-2. 그리는 순서 (아래 → 위) — "내 효과가 적 경고를 덮지 않게"
바닥 → **내 장판**(옅게) → 적 장판 채움 → 좀비·나 → 내 투사체(흐리게) → 적 투사체(밝게) → **적 장판·예고 테두리를 한 번 더** → 내 체력·피격 효과 → 화면 가장자리 경고·화면 밖 화살표 → HUD

### 7-3. 맞았을 때 알기
- 맞으면: 생존자 하얗게 번쩍 → 무적 시간 동안 깜빡, **맞은 쪽 화면 가장자리 빨강**, 짧은 소리·진동, 받은 피해 숫자(빨강, 작게).
- **장판 안에 있으면**: 발밑 장판 테두리가 크게 깜빡 + "치익" 소리 + 가장자리 빨강이 계속.
- **체력 30% 아래**: 가장자리가 붉게 두근 + 심장 소리.
- **결과 화면 '무엇에 당했나'**: 마지막 5번 맞은 것(예: "산성 웅덩이 4번, 도살자 식칼 1번") + **마지막 5초 동안 받은 피해 막대**(무엇에 얼마나).

### 7-4. 화면 정리
- 설정: **내 효과 투명도**(25~100%), 번쩍임 줄이기, 피해 숫자 켜고 끄기, 화면 흔들림.
- 내 효과가 많을수록 자동으로 옅게(한 장소에 겹친 내 장판은 합쳐서 한 번만 그림 — 투명도가 쌓여 불투명해지는 문제, 조사).
- 어둠·날씨는 보는 데 방해 안 되게 옅게.
- 반복 소리(조각 줍기 등)는 겹치면 하나로 합침(소리 피로 — 조사).

## 8. 손맛·편의
- **잘못 눌림**: 고르는 창은 뜬 뒤 0.6초 동안 카드가 흐리게 보이다 켜지고, **그 뒤에 새로 누른 손가락만** 받는다(`TapGuard`). 레벨 업·상자·밤 생존·전직·들고 가기·훈장 창 전부. 설정에 **'두 번 눌러 고르기'**(처음 누르면 카드가 커지고 한 번 더 누르면 고름).
- 레벨 업 순간 화면을 0.15초 느리게 → 창 (갑자기 멈춘 느낌 줄이기).
- 첫 판 안내는 짧게(첫 레벨 업·첫 적 장판·첫 보스 때 한 줄씩).
- 생존자마다 다른 손맛 — 시작 무기의 '힘 장부'는 같게(1레벨 초당 피해 18 안팎), 모양만 다르게.

## 9. 난이도 맞추는 방법 (감이 아니라 표로)
1. **힘 장부 모델**(`tools/power_model.py`): 시간마다 예상 레벨 → 예상 카드 → 예상 초당 피해. 좀비 체력·마릿수를 여기서 계산해 `data/` 에 넣는다.
2. **목표 표** (밤 안 / 밤 사이 모양이 같게):
   | 지표 | 목표 |
   |---|---|
   | 일반 좀비 '처음 맞고 쓰러지기까지' | 몸풀기 0.3초 · 몰아치기 0.6초 · 진화 뒤 0.3초(밀도로 압박) |
   | 화면 좀비 | §3 표 |
   | 첫 레벨 업 | 6초 안 |
   | 첫 진화 | 1밤 2:00 보스 상자 (판의 60% 이상) |
   | 보스 잡는 시간 | 보통 30~45초, 구역 보스 60초 |
   | '아슬아슬'(체력 20% 아래 갔다가 산 횟수) | 밤마다 1번 안팎 |
3. **사람 기준 목표** (기본 난이도 = 감염도 0):
   | 구역 | 느낌 | 보통 실력 그 밤 탈출 |
   |---|---|---|
   | 1 (1~5밤) | 배우는 곳 — 처음 하는 사람도 1밤은 2~3판 안에 깸 | 1밤 70%, 5밤 50% |
   | 2~3 | 조합·피하기가 손에 익음 | 40% |
   | 4~5 | 잘 짠 조합 + 피하기 | 25% |
   | 6 | 진짜 고수 | 10% |
   - **'개고수'는 감염도 1~10**(선택, 보상 큼). 단계마다 체력만이 아니라 **새 위협 하나씩**(예: 1 정예 +1, 3 보스 기술 +1, 5 침 좀비 2배, 7 다시 하기 0번…).
4. **시험**: 봇 3단계 + **'N밤부터 시작'**(그 밤의 예상 조합을 만들어 줌)으로 1·3·5·10·15·20·25·30밤을 잰다. 지표 + 화면 녹화로 눈 확인. 봇이 사람과 다른 점(반응 속도)은 사람 시험으로 보정.
