# 11. 코드 구조 — 전체 지도
> 코드가 어떤 구조로 짜였고 무엇으로 구성됐는지 한눈에 보는 문서. 처음 보는 사람은 이 문서부터 읽고 코드를 연다.

> **상태 표시**: ✅ 있음 · 🛠 v0.1에서 만듦 · ⏳ 나중 단계(옆에 단계 표시)
> **규칙**: 파일을 만들거나 옮기거나 지우면 **같은 작업 안에서 이 문서도 고친다.** 이 문서에 없는 코드 파일이 있으면 검사 도구(`tools/check_headers.py`)가 알려 준다. (문서 10 §9)
> 지금(2026-11-07)은 설계 단계라 대부분 🛠 이다. v0.1 구현 계획에서 최종 확정한다.

## 1. 한 장 요약
```
┌──────────────────────── 자동 로드 (게임 내내 하나만 있음) ────────────────────────┐
│  GameData  : data/*.json 숫자 표를 읽어 둠        SceneRouter : 화면 넘기기 + 선택값 전달 │
│  SaveData  : 저장·불러오기 (⏳v0.5)              AudioBus    : 효과음·음악 (⏳v0.2)     │
└───────────────────────────────────────────────────────────────────────────────────┘
        │ 숫자 읽기                     │ 화면 이동
        ▼                               ▼
 [타이틀] → [생존자 고르기] → [한 판 (Run)] → [결과] → (다시 고르기 / 타이틀)
                                    │
             ┌──────────────────────┼──────────────────────────┐
             ▼                      ▼                          ▼
        월드(보이는 것)          시스템(규칙 담당)              HUD(화면 위 UI)
   바닥·지형·조각·좀비·생존자   좀비 나오기·레벨 업·이벤트     경험치·시간·스킬 버튼
   무기·투사체·효과·빛          보스·탈출                      조이스틱·레벨 업 창
```
- **데이터(숫자)** 는 `data/` 표에만 → **GameData** 가 읽어서 모두에게 나눠 줌
- **한 판(Run)** 이 지휘자: 시간을 세고, 각 부분을 정해진 순서로 돌리고, 승패를 정함
- 부분끼리는 **신호(signal)** 로 알림 — "좀비가 쓰러졌다" → 조각 떨구기·처치 수 올리기·경험치

## 3. 화면 흐름
| 장면 파일 | 스크립트 | 하는 일 | 다음 |
|---|---|---|---|
| `scenes/title.tscn` | `scripts/ui/title_screen.gd` | 게임 이름, 누르면 시작 | 생존자 고르기 |
| `scenes/survivor_select.tscn` | `scripts/ui/survivor_select.gd` | 생존자 카드 4장(걷는 모습), 고르면 SceneRouter 에 기억 | 한 판 |
| `scenes/run.tscn` | `scripts/run/run.gd` | 한 판 5분 | 결과 |
| `scenes/result.tscn` | `scripts/ui/result_screen.gd` | 탈출/실패, 기록, 다시 하기 | 생존자 고르기 / 타이틀 |
| `scenes/shelter.tscn` | `scripts/meta/shelter_screen.gd` | 은신처 | ⏳v0.5 |

- 화면 사이에 넘길 값(고른 생존자, 지역, 감염도, 결과 기록)은 **SceneRouter** 가 들고 다닌다.

## 5. 한 순간(프레임)에 도는 순서
`run.gd` 가 아래 순서대로 각 부분을 부른다. **순서를 한곳에서 정해** 누가 먼저 움직이는지 헷갈리지 않게 한다.
```
1. 입력 읽기          Joystick → 이동 방향, SkillButton → 스킬 눌렸나
2. 생존자 움직이기    Survivor (빛 안인지 Lighting 에 물어봄)
3. 좀비 나오기        ZombieSpawner → ZombieHorde 에 추가
4. 좀비 움직이기      ZombieHorde: 생존자 쪽으로 + 서로 밀어내기 (칸 나누기로 가까운 것만)
5. 무기 쏘기          WeaponRack → 각 무기가 목표 찾기 → Projectiles / 바로 피해
6. 투사체 날리기      Projectiles: 움직이고 좀비와 부딪힘 확인
7. 피해 정리          쓰러진 좀비 → 신호 zombie_died → 조각·효과·처치 수
8. 조각 줍기          VaccineShards → 신호 shard_collected → LevelUp
9. 규칙 확인          LevelUp(카드 띄우면 일시 멈춤) · BossDirector · Extraction · 승패
10. 그리기            Lighting(어둠) → Hud 숫자 갱신
```

## 6. 주요 신호 (누가 알리고, 누가 듣나)
| 신호 | 알리는 곳 | 듣는 곳 | 뜻 |
|---|---|---|---|
| `zombie_died(position, kind)` | ZombieHorde | VaccineShards, Effects, Run(처치 수) | 좀비가 쓰러짐 |
| `shard_collected(amount)` | VaccineShards | LevelUp | 경험치 얻음 |
| `leveled_up(choices)` | LevelUp | LevelUpPanel, Run(멈춤) | 카드 고를 차례 |
| `card_chosen(card_id)` | LevelUpPanel | LevelUp, WeaponRack | 고른 카드 적용 |
| `survivor_damaged(amount)` | Survivor | Effects, Camera(흔들림), TopBar | 생존자가 맞음 |
| `survivor_died()` | Survivor | Run | 실패 |
| `skill_used(skill_id)` | Survivor | SkillButton(다시 쓰기 시작), Effects | 스킬 씀 |
| `boss_spawned(boss_id)` | BossDirector | Banner, Camera | 보스 등장 알림 |
| `extraction_started(position)` | Extraction | ExtractionArrow, Banner | 착륙 지점 표시 |
| `extracted()` | Extraction | Run | 탈출 성공 |

## 9. 픽셀 그림 만드는 길
```
art/source/survivor_police.txt   (글자 지도: 한 글자 = 한 점, 맨 위에 팔레트·머리말)
        │  tools/build_sprites.py  (글자 지도 → 그림 묶음 PNG, 동작별 줄)
        ▼
art/sprites/survivor_police.png  → SurvivorAnimator 가 걷기·공격 장면을 골라 보여 줌
```
- 그림을 고칠 때는 **글자 지도만 고치고** 도구를 다시 돌린다. PNG를 직접 고치지 않는다.

## 10. 따라 해 보기 — 자주 하는 일
| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 숫자 바꾸기 (예: 권총 피해) | `data/weapons.json` 의 `pistol` 만 |
| 새 무기 넣기 | ① `data/weapons.json` 에 칸 추가 ② `scripts/weapons/새무기.gd` (공통 틀 이어받기) ③ 그림 글자 지도 ④ 이 문서 §8 |
| 새 좀비 넣기 | ① `data/zombies.json` ② 그림 글자 지도 ③ 특수 행동이 있으면 `zombie_horde.gd` 의 행동 목록에 추가 ④ 이 문서 |
| 새 생존자 넣기 | ① `data/survivors.json` ② 스킬 파일 ③ 그림 ④ 생존자 고르기 카드는 표를 읽어 자동으로 생김 |
| 한 판 순서 바꾸기 | `scripts/run/run.gd` 의 프레임 순서 (§5) 한 곳만 |
