# 11. 코드 구조 — 전체 지도
> 코드가 어떤 구조로 짜였고 무엇으로 구성됐는지 한눈에 보는 문서. 처음 보는 사람은 이 문서부터 읽고 코드를 연다. (2026-11-07 끝없는 밤 묶음 1 기준)

> **상태 표시**: ✅ 있음 · ⏳ 나중 단계(옆에 단계 표시)
> **규칙**: 파일을 만들거나 옮기거나 지우면 **같은 작업 안에서 이 문서도 고친다.** 이 문서에 없는 코드·장면·도구 파일은 `tools/check_headers.py` 가 찾아낸다. (문서 10 §9·§10)

## 1. 한 장 요약
```
┌──────────────── 자동 로드 (게임 내내 하나만 있음) ────────────────┐
│ GameData    data/*.json 숫자 표를 읽어 둠                          │
│ SaveData    user://save.json 저장 (고철·은신처·해금·업적·도감·기록·설정) │
│ SceneRouter 화면 넘기기 + 고른 생존자·감염도·도전·판 목표 + 판 끝 정산 │
│ SoundPlayer 효과음(변형·높낮이)·반복 소리 + MusicMixer(밤마다 곡·보스·헬기) │
└───────────────────────────────────────────────────────────────────┘
        │ 숫자 읽기                     │ 화면 이동
        ▼                               ▼
 [타이틀] → [생존자 고르기(+감염도)] → [한 판 (Run): 첫째 밤 3분 → 헬기 → 둘째 밤 → …] → [결과] → (바로 다시 / 생존자 고르기 / 은신처)
    ├→ [은신처] [도감] [업적]  (목록 화면, 뒤로 = 타이틀)
    └→ 겹쳐 뜨는 창: [오늘의 도전] → 한 판, [설정] (멈춤 메뉴에서도)
                                    │
             ┌──────────────────────┼──────────────────────────┐
             ▼                      ▼                          ▼
        World (보이는 것)        Systems (규칙 담당)           Hud (화면 위 UI)
   바닥·소품·장판·조각·좀비      좀비 나오기·레벨 업·전직       정보 줄·조이스틱·스킬 버튼
   생존자·무기·투사체·탈출       보스·스킬·기록                 알림·화살표·레벨 업·전직·멈춤
   효과·빛
```
- **숫자**는 `data/` 표에만 → GameData 가 읽어서 나눠 줌
- **한 판(run.gd)** 이 지휘자: 시간을 세고, 각 부분을 정해진 순서로 돌리고, 승패를 정함
- 부분끼리는 **RunContext**(한 판 묶음 상자)로 서로를 찾고, 일이 생기면 **신호(signal)** 로 알림

## 4. 자동 로드 (`scripts/autoload/`)
| 파일 | 이름 | 하는 일 |
|---|---|---|
| `game_data.gd` | GameData | `data/*.json` 을 읽어 두고 `entry("weapons","pistol")`·`rules("extraction")` 으로 꺼내 줌. 판 밖 성장 표는 `META_TABLE_NAMES` |
| `save_data.gd` | SaveData | `user://save.json` 하나에 고철·은신처·해금·업적·도감·기록·설정·오늘의 도전·누적 숫자. 판 끝·강화·설정 바꿀 때·앱 나갈 때 저장(임시 파일 → 이름 바꾸기, 예비 파일 `.backup`), 깨지면 예비 → 처음 값. `--autoplay` 면 파일을 안 건드림(`--save=경로` 면 그 파일) |
| `scene_router.gd` | SceneRouter | 화면 이동, 고른 생존자·감염도·오늘의 도전 규칙·판 목표·판 결과·정산 보관, 판 끝에 `RunSettlement.settle()`, 명령줄 시험 옵션(`--autoplay` 등) |
| `sound_player.gd` | SoundPlayer | `audio/` 의 `<이름>_<번호>.wav` 변형 모아 두고 재생, 중요한 소리 전용 칸, 반복 소리(헬기). 음악은 자식 `music_mixer.gd`(MusicMixer)에 맡김 |
| `music_mixer.gd` | (SoundPlayer 의 자식) | 밤마다 다른 곡 묶음 3층(위험도로 섞기), 보스·분노·헬기 곡으로 부드럽게 바꿨다 돌아오기, 화면 음악 한 곡 |

- 자동 로드 순서: GameData → SaveData → SceneRouter → SoundPlayer (SceneRouter 가 켤 때 저장의 '마지막 감염도'를 읽어서 저장이 먼저. 소리 크기는 SoundPlayer 준비 뒤 한 박자 늦게 넣음)

| `unlocks.gd` | Unlocks | 생존자 해금 조건(야구선수 3밤·사냥꾼 누적 5,000), 잠김 칸 목록 |

## 6. 한 순간(프레임)에 도는 순서 — `run.gd` 의 `_physics_process`
```
1·2. 입력 → 생존자 이동 (차에 막힘)          Survivor.move_step, Props.push_out
     스킬 버튼 눌렸으면 스킬                   SkillRunner.try_use
3.   좀비 나오기·이벤트                        ZombieSpawner.update, HordeEvents.update
4.   좀비 움직이기·특수 행동·닿으면 피해       ZombieHorde.update (→ ZombieAbilities)
     보스 기술(예고 → 공격)·분노               BossDirector.update (→ BossAttacks → BossMoves*)
     침·식칼·웅덩이·예고 원/선                 Hazards.update
5.   무기 공격·무기 장판                       WeaponRack.update → 각 Weapon, WeaponZones
6.   투사체 날리기·맞히기                      ProjectilePool.update
     장판 피해                                 AreaEffects.update
8.   조각 줍기 → 경험치, 구급함 → 회복, 상자·자석·폭탄·냉각   VaccineShardField.update → LevelUp, HealthPacks.update, Pickups.update → RunRewards
9.   탈출 규칙                                 Extraction.update
     창 띄우기 (전직 → 보물 상자 → 카드)       Promotion / RunRewards / LevelUp → 멈춤
10.  빛·연속 처치·카메라·바닥·소품·HUD(밤 이름·연속·보스 체력 줄)·기록·음악(위험도·보스·헬기)
```
- 레벨 업·전직 창이 열리면 `get_tree().paused = true`, 고르면 Hud 가 푼다. **헬기 버티기·보스 공격(예고 포함) 중엔 창을 미룬다.**
- 헬기를 타면(`extracted`) NightFlow 가 멈추고 '밤 생존' 창 → [다음 밤] 이면 `elapsed_seconds` 만 0 으로(판 전체 시간 `run_seconds` 는 계속).

- 새 공격 방식이 아니면 **숫자 표만 고쳐서** 무기를 더할 수 있다 (`behavior`·`look` 을 기존 것으로).
- 진화: `weapons.json` 무기마다 `evolution` = 짝 장비(`gear`)·이름·아이콘·진화 숫자 전부(`numbers`). 5단계 + 짝 장비면 레벨 업·보물 상자에 진화 카드가 먼저 나온다.

### 자주 쓰는 명령
```
# 그림 / 소리 다시 만들기
py -3 tools/build_sprites.py
py -3 tools/build_sounds.py
# 머리말 검사
py -3 tools/check_headers.py
# 자동 플레이 20판 (화면 없이 최대 속도) → 통계
"C:/Users/kbs/Godot/Godot_v4.7.2-stable_win64_console.exe" --headless --path . res://scenes/run.tscn --fixed-fps 60 -- --autoplay=보통 --survivor=police --runs=20 --stats=tools/out/balance/police_보통.jsonl
py -3 tools/balance_stats.py tools/out/balance
# 웹으로 내보내기 → ../survivor-web 에서 커밋·push 하면 공개 링크 갱신
py -3 tools/export_web.py
# 무기 연출 미리보기 (창이 뜸, --weapons=shotgun,molotov 로 골라 볼 수도)
"…/Godot_v4.7.2-stable_win64_console.exe" --path . -s tools/weapon_showcase.gd -- --survivor=police --capture=tools/out/showcase
# 화면 캡처 (창이 뜸)
"…/Godot_v4.7.2-stable_win64_console.exe" --path . res://scenes/run.tscn --fixed-fps 60 -- --autoplay=보통 --capture=<폴더>
```
- 자동 플레이 옵션: `--autoplay=초보|보통|고수` · `--survivor=police|firefighter|courier|nurse` · `--branch=random|0|1|2|<갈래 이름>` · `--runs=N` · `--stats=파일` · `--capture=폴더` · `--speed=배속` · `--infection=0~10`(감염도) · `--daily`(오늘의 도전 생존자·규칙으로) · `--save=파일`(시험용 저장 파일 — 없으면 봇은 저장하지 않음)
