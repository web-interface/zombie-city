# 11. 코드 구조 — 전체 지도
> 코드가 어떤 구조로 짜였고 무엇으로 구성됐는지 한눈에 보는 문서. 처음 보는 사람은 이 문서부터 읽고 코드를 연다. (v0.1 실제 코드 기준, 2026-11-07)

> **상태 표시**: ✅ 있음 · ⏳ 나중 단계(옆에 단계 표시)
> **규칙**: 파일을 만들거나 옮기거나 지우면 **같은 작업 안에서 이 문서도 고친다.** 이 문서에 없는 코드·장면·도구 파일은 `tools/check_headers.py` 가 찾아낸다. (문서 10 §9·§10)

---

## 1. 한 장 요약
```
┌──────────────── 자동 로드 (게임 내내 하나만 있음) ────────────────┐
│ GameData    data/*.json 숫자 표를 읽어 둠                          │
│ SceneRouter 화면 넘기기 + 고른 생존자·판 결과 전달 + 시험 옵션      │
│ SoundPlayer 효과음(변형·높낮이)·반복 소리·음악 3층 섞기             │
└───────────────────────────────────────────────────────────────────┘
        │ 숫자 읽기                     │ 화면 이동
        ▼                               ▼
 [타이틀] → [생존자 고르기] → [한 판 (Run)] → [결과] → (다시 하기 / 생존자 바꾸기)
                                    │
             ┌──────────────────────┼──────────────────────────┐
             ▼                      ▼                          ▼
        World (보이는 것)        Systems (규칙 담당)           Hud (화면 위 UI)
   바닥·소품·장판·조각·좀비      좀비 나오기·레벨 업·전직       정보 줄·조이스틱·스킬 버튼
   생존자·무기·투사체·탈출       보스·스킬·기록                 알림·화살표·레벨 업·전직·멈춤
   효과·빛
```
- **숫자**는 `data/` 표에만 → GameData 가 읽어서 나눠 줌
- **한 판(run.gd)** 이 지휘자: 시간을 세고, 각 부분을 정해진 순서로 돌리고, 승패를 정함
- 부분끼리는 **RunContext**(한 판 묶음 상자)로 서로를 찾고, 일이 생기면 **신호(signal)** 로 알림

## 6. 한 순간(프레임)에 도는 순서 — `run.gd` 의 `_physics_process`
```
1·2. 입력 → 생존자 이동 (차에 막힘)          Survivor.move_step, Props.push_out
     스킬 버튼 눌렸으면 스킬                   SkillRunner.try_use
3.   좀비 나오기                               ZombieSpawner.update
4.   좀비 움직이기·닿으면 피해                 ZombieHorde.update
     보스 행동(예고·돌진)                      BossDirector.update
5.   무기 공격·무기 장판                       WeaponRack.update → 각 Weapon, WeaponZones
6.   투사체 날리기·맞히기                      ProjectilePool.update
     장판 피해                                 AreaEffects.update
8.   조각 줍기 → 경험치, 구급함 줍기 → 회복   VaccineShardField.update → LevelUp, HealthPacks.update
9.   탈출 규칙                                 Extraction.update
     창 띄우기 (전직 먼저, 그다음 카드)        Promotion / LevelUp → 멈춤
10.  빛·카메라·바닥·소품·HUD·기록·음악 위험도
```
- 레벨 업·전직 창이 열리면 `get_tree().paused = true`, 고르면 Hud 가 푼다. **헬기 버티기·보스 돌진 중엔 창을 미룬다.**

| `weapon.gd` | **공통 틀 Weapon**: 단계·진화(진화하면 진화 숫자 전부), 지금 숫자, 다시 공격 시간(공격 속도 반영), 사거리·범위, 이름·아이콘, 치명타 더하기·기절·때리기 도우미 |

| `line_weapon.gd` | 일직선 꿰뚫기 — 소방 호스(물줄기)·테이프 건(묶기) |
| `weapon_rack.gd` | 무기·장비 칸, 진화, 공격 방식 → 스크립트 연결, 빛 층(어둠 안 받음)에 연출·장판을 만듦 |
| `weapon_visuals.gd` | **무기 연출 WeaponVisuals**: 번개·하늘 번개·물줄기·테이프·폭발·충격파·전기·화염 고리·폭격 예고·화면 번쩍 (개수 상한) |
| `weapon_zones.gd` | **무기 장판 WeaponZones**: 불·연기 구름·조명탄(빛 기둥) — 0.25초마다 피해·느려짐 (전직 스킬 장판은 world/area_effects.gd) |
| `particle_buffer.gd` | 연출 알갱이 고리 버퍼(불꽃·불씨·물방울·파편) — 매 프레임 새 배열 없이 |
| `projectile_pool.gd` | 날아가는 투사체 전부 (튕기기·맞힌 자리 폭발·맞히면 회복), 빛 층에 그림 |
- 새 공격 방식이 아니면 **숫자 표만 고쳐서** 무기를 더할 수 있다 (`behavior`·`look` 을 기존 것으로).
- 진화: `weapons.json` 무기마다 `evolution` = 짝 장비(`gear`)·이름·아이콘·진화 숫자 전부(`numbers`). 5단계 + 짝 장비면 레벨 업·보물 상자에 진화 카드가 먼저 나온다.

## 11. 그림·소리 만드는 길
```
art/source/parts_people.txt (부품 글자 지도) ─┐
art/source/sprites.txt      (한 장 그림)     ├─ tools/build_sprites.py (+ tools/pixel_png.py) ─▶ art/sprites/*.png (+ 하얀 실루엣)
art/source/outfits.json     (옷·색 표)       ─┘
audio/source/music_scores.txt (악보) ─ tools/build_sounds.py (+ tools/chiptune.py) ─▶ audio/*.wav
```
- 그림·소리는 **원본만 고치고 도구를 다시 돌린다.** PNG·WAV 를 직접 고치지 않는다.

## 12. 도구 (`tools/`)
| 파일 | 하는 일 |
|---|---|
| `build_sprites.py` · `pixel_png.py` | 글자 지도 → PNG (생존자 16벌·좀비 4종·보스·소품·아이콘·바닥·빛) |
| `build_sounds.py` · `chiptune.py` | 8비트 효과음·음악 만들기 (파이썬 기본 라이브러리만) |
| `autoplay.gd` | 자동 플레이 봇(초보·보통·고수), 화면 캡처 (히든·진화·진화 짝 카드를 챙김) |
| `weapon_showcase.gd` | 무기 연출 미리보기(창이 뜸): 전용 무기 최고 단계 → 진화 → 히든·진화 카드 창 → 히든 스킬 컷인을 차례로 PNG 로 |
| `check_headers.py` | 머리말·폴더 README·코드 지도 검사 |
| `balance_stats.py` | 자동 플레이 기록 → 탈출률·재미 지표 표 |
| `export_web.py` | 웹용으로 내보내기 → `../survivor-web`(gh-pages) + `web/` 파일(미리보기 그림·폰 소리 켜기)·.nojekyll |

### 자주 쓰는 명령
```
# 그림 / 소리 다시 만들기
py -3 tools/build_sprites.py
py -3 tools/build_sounds.py
# 머리말 검사
py -3 tools/check_headers.py
# 자동 플레이 20판 (화면 없이 최대 속도) → 통계
"C:/Users/kbs/Godot/Godot_v4.7.2-stable_win64_console.exe" --headless --path . res://scenes/run.tscn --fixed-fps 60 -- --autoplay=보통 --survivor=police --runs=20 --stats=tools/out/balance/police_보통.jsonl
py -3 tools/balance_stats.py tools/out/balance
# 웹으로 내보내기 → ../survivor-web 에서 커밋·push 하면 공개 링크 갱신
py -3 tools/export_web.py
# 무기 연출 미리보기 (창이 뜸, --weapons=shotgun,molotov 로 골라 볼 수도)
"…/Godot_v4.7.2-stable_win64_console.exe" --path . -s tools/weapon_showcase.gd -- --survivor=police --capture=tools/out/showcase
# 화면 캡처 (창이 뜸)
"…/Godot_v4.7.2-stable_win64_console.exe" --path . res://scenes/run.tscn --fixed-fps 60 -- --autoplay=보통 --capture=<폴더>
```
- 자동 플레이 옵션: `--autoplay=초보|보통|고수` · `--survivor=police|firefighter|courier|nurse` · `--branch=random|0|1|2|<갈래 이름>` · `--runs=N` · `--stats=파일` · `--capture=폴더` · `--speed=배속`

## 13. 따라 해 보기 — 자주 하는 일
| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 숫자 바꾸기 (예: 권총 피해) | `data/weapons.json` 의 `pistol` 만 |
| 새 무기 (기존 공격 방식) | ① `data/weapons.json` 에 칸(behavior·look·levels·evolution) ② 생존자 `weapon_pool` 이나 `run_rules.json` build.common_weapons ③ `art/source/sprites.txt` 에 `icon_<이름>`·`icon_<이름>_evolved` ④ 그림 도구 실행 |
| 새 장비 | ① `data/gear.json` (새 능력치면 `run_rules.json` survivor_base_stats 에도 + 읽는 코드) ② 공용이면 build.common_gear, 전용이면 생존자 gear_pool |
| 새 히든 스킬 | ① `data/skills.json` (`is_hidden`, 효과 조각 — 새 조각이면 `hidden_skill_effects.gd`) ② 생존자 `hidden_skill` |
| 보물 상자에서 강화 주기 (총책임관) | `LevelUp.roll_upgrade_cards(n)` 으로 n 장 정하고 → 슬롯이 멈출 때마다 `LevelUp.apply_card(card)`. 진화 먼저 보여 줄지는 `LevelUp.has_evolution_ready()` |
| 새 공격 방식 | ① `scripts/weapons/<방식>_weapon.gd` (Weapon 이어받기) ② `weapon_rack.gd` 의 BEHAVIOR_SCRIPTS ③ 이 문서 §9 |
| 새 좀비 | ① `data/zombies.json` ② `outfits.json` 의 zombie_kinds 색 ③ 그림 도구 ④ `spawn_curve.json` kinds |
| 새 생존자 | ① `data/survivors.json` ② 스킬·전직 표 ③ `outfits.json` 옷 ④ 고르기 화면은 표를 읽어 자동 |
| 새 전직 갈래 | `data/promotions.json` (스킬 바꾸기 종류는 표 맨 위 설명) + 옷 |
| 한 프레임 순서 | `scripts/run/run.gd` 의 `_physics_process` 한 곳만 |
