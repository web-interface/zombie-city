## 폴더 구조 (요약 — 자세한 코드 지도는 [11_코드구조.md](11_코드구조.md))
```
survivor/
├─ project.godot        엔진 설정
├─ scenes/              타이틀 · 생존자 고르기 · 게임 · 결과 · (은신처)
├─ scripts/
│  ├─ game/             한 판 진행: 생존자, 좀비, 무기, 투사체, 백신 조각, 이벤트, 빛
│  ├─ ui/               HUD, 레벨 업, 스킬 버튼, 조이스틱, 결과
│  ├─ meta/             저장, 은신처, 해금, 숙련도 (v0.5~)
│  └─ tools/            자동 플레이, 화면 캡처, 통계
├─ data/                생존자·무기·장비·진화·좀비·이벤트·감염도 표 (JSON) — 03 문서의 숫자
├─ art/                 픽셀 그림 (생존자·좀비·타일·아이콘) + 그림 만드는 스크립트
├─ audio/               효과음·음악
├─ fonts/               Pretendard, Galmuri + 사용 조건
└─ docs/                이 문서들
```
- 지금 있는 시험용 파일(main.tscn, scripts/ui.gd·joystick.gd·upgrades.gd)은 v0.1 구현 때 이 구조로 옮기거나 새로 쓴다.
- **숫자는 data/ 표에만** 둔다 → 밸런스는 표만 고치면 됨.
- 좀비 300마리 성능: 물리 엔진 대신 거리 계산 + 칸 나누기(가까운 것끼리만 계산), 총알·좀비·조각은 미리 만들어 두고 재사용(풀링), 그리기는 한 번에 몰아서.

## 저장
- 기록·설정은 폰 안 `user://save.json` (메타 성장 생기면)

## 시험 방법
- **자동 플레이 모드**: 실행할 때 `-- --autoplay --speed=4 --shots=폴더` → 알아서 피하고 강화 고르며 진행, 정해진 시점마다 화면 캡처
- 스크립트 오류 확인: 실행 기록에 오류(ERROR / SCRIPT ERROR)가 없는지
- 사람 시험: PC 창(폰 크기)에서 마우스로, 그다음 실제 폰(웹 링크)

### 웹 내보내기 (`export_presets.cfg` 설명 — Godot 이 저장할 때 이 파일의 주석을 지워서 여기에 적음)
| 항목 | 값 | 이유 |
|---|---|---|
| 내보내기 이름 | `Web` | `tools/export_web.py` 가 이 이름으로 부름 |
| 쓰레드 | **끔** (`variant/thread_support=false`) | 쓰레드를 켜면 서버가 특별한 보안 머리글(COOP/COEP)을 보내야 하는데 GitHub Pages 는 못 보냄. 끄면 아무 데서나 열림 |
| 앱처럼 설치(PWA) | **끔** | 모바일은 반응형 웹으로만 (홈 화면 앱처럼 만들지 않음) |
| 화면 맞추기 | `canvas_resize_policy=2` (창에 맞춤) | 폰 화면을 꽉 채우고, 게임 쪽 정수배 키우기가 픽셀을 지킴 |
| 더 넣는 파일 | `data/*.json` | 숫자 표는 Godot 리소스가 아니라 글 파일이라 따로 넣어야 확실히 들어감 |
| 빼는 파일 | `tools/out/*` | 시험 결과·캡처 |
| head 에 넣는 것 | 설명·링크 미리보기(og:title·description·image), 바탕색 | 카톡 등에 링크를 보내면 제목·그림이 뜨게 |
| 내보내는 곳 | `../survivor-web/` | 저장소의 `gh-pages` 가지를 그 폴더에 따로 열어 둠(git worktree). 소스(main)와 웹 파일(gh-pages)을 나눔 |

- 내보내기 도구(템플릿)는 공식 `Godot_v4.7.2-stable_export_templates.tpz`(1.3GB)에서 **웹용 9개 파일만** `%APPDATA%\Godot\export_templates\4.7.2.stable\` 에 꺼내 둠 (체크섬 확인). 안드로이드는 그때 다시 꺼냄.
- 다시 올리기: `py -3 tools/export_web.py` → `../survivor-web` 에서 커밋·push (push 는 `-c credential.username=web-interface`).
