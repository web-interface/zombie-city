# 12. 검수와 난이도 조절 — 그리고 "재밌는가"
> 만든 것을 누가, 언제, 무엇으로 확인하는지 정한 문서. **검수관**과 **난이도 테스터** 에이전트는 필수다 (사용자 요청 2026-11-07).

## 1. 역할
| 역할 | 누구 | 하는 일 | 정의 파일 |
|---|---|---|---|
| **검수관** | 에이전트 `game-inspector` | 코드·규칙·구조 지도·AI 티·버그 위험·성능 위험을 점검하고 고칠 목록을 낸다 (직접 고치지 않음) | `.claude/agents/game-inspector.md` |
| **난이도 테스터** | 에이전트 `balance-tester` | 자동 플레이 봇으로 수십~수백 판을 돌려 통계를 내고, 목표와 다르면 `data/` 숫자 조정안을 내고 다시 돌려 확인한다 | `.claude/agents/balance-tester.md` |
| **재미 판정** | 사용자 (최종) + 난이도 테스터의 재미 지표 | 숫자는 참고, **"한 판 더 하고 싶은가"는 사람이 정한다** | — |
| 만드는 사람 | Claude (메인) | 검수·테스트 결과를 반영해 고친다 | — |

- 에이전트를 돌릴 때는 한국어 역할 이름(검수관 / 난이도 테스터)으로 부르고, 진행 화면(agent-monitor)을 띄운다.

## 2. 언제
| 때 | 검수관 | 난이도 테스터 |

| 단계(v0.x) 끝날 때 | ✅ 전체 | ✅ 전체 (생존자 × 갈래 × 봇 실력) |

## 3. 검수관 점검표
0. **경고 보기**: Godot 를 `-d` 로 실행해야 스크립트 경고가 보인다
1. **규칙**: 문서 10 — 머리말 4칸, 이름 안 줄임, 정적 타입, 함수 40줄·파일 300줄, 숫자는 `data/`, 한국어 "왜" 주석, 옛 코드 주석 없음
2. **지도**: 문서 11 과 실제 파일·신호·데이터가 같은가
3. **도구 결과**: `tools/check_headers.py` 통과, Godot 오류·경고 0
   - 알려진 잡음(세지 않음): 끌 때 나오는 `ObjectDB instances were leaked` · `resources still in use` 중 **소리(AudioStreamWAV·AudioStreamPlaybackWAV)만** 있는 것. 끄는 순간 재생 중이던 소리를 소리 쓰레드가 아직 못 치운 것이고, 판 수만큼 늘지 않아 메모리 누수가 아님 (2026-11-07 마지막 검수 확인). 소리 말고 다른 것이 섞이면 문제로 본다.
4. **버그 위험**: 0으로 나누기, 빈 배열, 지운 노드 다시 쓰기, 멈춤(pause) 중 처리, 같은 신호 두 번 연결
5. **성능 위험**: 매 프레임 새로 만드는 것, 좀비 수 × 좀비 수 계산, 불필요한 노드
6. **AI 티**: 문서 06 "AI 티 안 나게" 표 — 뻔한 말·영어 라벨·이모지·대칭 그림·똑같은 소리 반복
7. **품질 기준**: 문서 02 §12 (반응, 모든 것이 움직임, 손맛, 연출)
- 결과는 **심각 / 고치면 좋음 / 칭찬** 세 칸으로, 파일:줄 과 함께.

## 4. 난이도 테스터
### 봇 실력 3단계 (`tools/autoplay.gd`)
| 봇 | 움직임 | 카드 고르기 | 스킬 |
|---|---|---|---|
| **초보** | 가까운 좀비만 보고 반대로, 반응 0.5초 늦음, 가끔 멈춤 | 무작위 | 준비되면 아무 때나 |
| **보통** | 둘러싼 좀비 전체를 보고 빈 쪽으로, 조각·구급함도 주움, 방향은 0.15초마다 다시 정함(사람처럼), 착륙 원 바깥에서 기다렸다가 헬기 12초 전에 들어감. 근접 무기면 붙어서 싸우고, 원거리 무기면 보스와 75 안쪽을 지킴 | 가진 무기 강화 우선 | 위험할 때 |
| **고수** | 보통(반응 늦춤 없음) + 빛(가로등) 쪽으로 끌어들임, 보스 예고선 피함, 키우던 무기 집중 | 조합 점수(진화·시너지) | 가장 효과 좋은 순간 |

### 돌리는 법
- Godot 를 화면 없이 최대 속도로 실행: `--headless --fixed-fps 60 -- --autoplay=보통 --survivor=police --branch=random --runs=20 --max-nights=3 --stats=tools/out/balance/….jsonl` (밤은 끝이 없어서 `--max-nights` 로 시험 밤 수를 정함)
- **배속(`--speed`)은 쓰지 않는다**: 한 걸음이 커져 총알이 좀비를 뚫고 지나가 통계가 틀려진다 (2026-11-07 검수관 확인: 보통 속도 3/3 탈출 vs 배속 8 0/3)
- 판마다 기록: 버틴 시간, 탈출 여부, 쓰러진 이유(어느 좀비·보스), 레벨, 레벨 업 시각, 체력 변화, 화면 좀비 수, 처치 수, 고른 카드·전직
- `tools/balance_stats.py` 가 모아서 표로 요약 → `tools/out/balance/report.md`

### 목표 (감염도 0)
| 지표 | 목표 |
|---|---|
| 첫째 밤 생존률 — 고수 / 보통 / 초보 | 65~80% / 30~40% / 5~15% (사용자 '1라운드조차 어렵게', 2026-11-07) |
| 둘째 밤 / 셋째 밤 (보통 봇) | 10~20% / 3~8% (고수는 셋째~넷째 밤까지) |
| 보스 처치 시간 | 30~60초 (사용자 '보스 진짜 잡기 어렵게') |
| 생존자별·갈래별 탈출률 차이 (보통 봇) | ±15%p 안 |
| 가장 많이 쓰러지는 때 | 한 구간(예: 보스 1)에 50% 넘게 몰리지 않기 |

### 조정 규칙
- 숫자는 **`data/*.json` 에서만**, 한 번에 2~3개만 바꾸고 다시 돌린다.
- 바꾼 것과 이유·전후 통계를 `docs/balance_log.md` 에 남긴다 (사용자가 볼 수 있게 쉬운 말로).

## 5. "재밌는가" — 재미 지표
숫자로 재미를 다 잴 수는 없지만, **재미없는 신호**는 잡을 수 있다. 난이도 테스터가 매번 같이 낸다.
| 재미 요소 | 지표 (보통 봇) | 목표 | 벗어나면 |
|---|---|---|---|
| 성장이 자주 온다 | 레벨 업 간격 | 처음 1분 8~15초, 2분 뒤 10~20초 (처음 20~35초였는데 '레벨 20 ≈ 3:30' 목표와 부딪쳐 고침, 1차 밸런스) | 경험치 곡선·조각 양 조정 |
| 위기가 온다 | 탈출한 판에서 가장 낮았던 체력 | 절반 이상의 판에서 30% 밑으로 한 번 | 나오는 속도·피해 조정 |
| 지루한 구간이 없다 | 20초 넘게 레벨 업·보스·이벤트·알림이 하나도 없는 구간 | 판당 0~1번 | 이벤트·좀비 곡선 조정 |
| 아슬아슬하다 | 체력 30% 밑으로 갔다가 살아난 횟수 | 판당 2~4번 | 0이면 너무 쉬움, 6+면 너무 가혹 |
| 점점 강해지는 맛 | 분당 처치 수 | 매 분 늘어남 (5분째가 1분째의 4배+) | 무기 성장·좀비 수 조정 |
| 화면이 꽉 찬다 | 4분대 화면 좀비 수 | 120~300 | 나오는 속도 조정 |
| 보스가 고비다 | 보스 처치까지 걸린 시간 | 30~60초 | 보스 체력·기술 조정 |
| 전직이 체감된다 | 전직 전후 30초 처치 속도 | +30% 이상 | 전직 효과 키우기 |
| 마지막이 짜릿하다 | 탈출 8초 동안 체력이 깎인 판 비율 | 60%+ | 탈출 때 좀비 몰림 조정 |
| 고르는 게 의미 있다 | 판마다 고른 카드 조합이 겹치는 정도 | 같은 생존자 10판 중 똑같은 빌드 2판 이하 | 카드 확률·강화 효과 조정 |

## 6. 스토어 별점 4.5 이상 기준 (사용자 요청 2026-11-07)
모바일 게임 별점을 깎는 건 대부분 **"재미없음"보다 "짜증남"**이다 (튕김, 끊김, 억지 광고·결제, 저장 날아감, 불공정한 난이도). 출시(v1.0) 전에 아래를 **전부** 통과해야 한다. 검수관이 v0.9부터 이 표도 점검한다.
| 항목 | 기준 |
|---|---|
| 튕김 | 자동 플레이 1,000판 동안 0번, 실제 폰 3종 이상에서 0번 |
| 끊김 | 중급 안드로이드 폰에서 좀비 300마리 60fps, 저가 폰 30fps 이상 |
| 시작 속도 | 앱 켜고 3초 안에 타이틀, 판 시작 1초 안 |
| 저장 | 판 끝날 때·앱 나갈 때 저장, 강제 종료해도 은신처 진행 안 날아감 |
| 공정함 | 보스 공격 전 예고, 화면 밖에서 안 보이는 공격 없음, 이유 모를 죽음 없음 (쓰러진 이유를 결과 화면에 표시) |
| 첫 5분 | 설명 글 없이 첫 판에 조작을 알게 됨, 첫 판이 너무 어렵지 않음 (초보 봇 기준 3분 이상 버팀) |
| 돈 | **억지 광고·과금 없음.** 넣더라도 선택형(보는 사람만 보상), 능력을 돈으로 사지 않음 |
| 폰 배려 | 발열·배터리 (30분 연속 플레이 시험), 앱 크기 150MB 이하, 인터넷 없이도 플레이 |
| 다듬기 | 맞춤법·띄어쓰기 검사, 잘린 글자 없음, 모든 버튼 눌림 반응, 소리·진동 끄기 |
| 별점 부탁 | **탈출 성공 직후**에만, 3판 이상 한 사람에게, 한 번만 (진 뒤엔 절대 안 물음) |
| 의견 창구 | 설정에 "의견 보내기", 리뷰에 답글, 업데이트 꾸준히 (출시 후 첫 달 2번 이상) |
- 솔직히: 별점은 출시 후 사람들이 정하는 거라 보장할 수는 없다. 대신 **별점을 깎는 이유를 미리 다 없애는 것**을 목표로 한다.

### 사람이 보는 재미 (사용자 시험 때 물어볼 것)
1. 한 판 끝나고 **바로 한 판 더** 하고 싶었나?
2. 가장 신났던 순간 / 가장 짜증 났던 순간은?
3. 전직 고를 때 **고민**됐나? (뻔한 정답이 있었나)
4. 5분이 길었나 짧았나?
