## 원칙
- 장르(자동 공격 생존 액션)만 참고하고, **이름·캐릭터·그림·음악은 전부 우리 것**으로 만든다. 기존 게임을 그대로 베끼지 않는다.
- 문서를 먼저 고치고, 코드는 문서를 따라간다. 바뀐 결정은 [09_결정기록.md](09_결정기록.md)에 날짜와 함께 남긴다.
- 숫자(밸런스)는 직접 해 보고 조정한다. 문서의 숫자는 출발점이다.
- 단계마다 [02 §12 고급 게임 품질 기준](02_게임플레이.md)으로 점검한다.
