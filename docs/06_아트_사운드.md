## 그림 규칙
| 항목 | 값 |
|---|---|
| 게임 화면 해상도 | **180 × 320 점**을 폰 화면에 정수배로 키움 (흐리지 않게) |
| 사람·좀비 크기 | **16 × 16** (테두리 1점, 짙은 남색 `#16171f`) |
| 보스 크기 | **24 × 24 이상** (보스마다 다름) |
| 작은 것 | 백신 조각 5×5, 톱날 드론 7×7, 총알 2×2, 아이콘 12×12 |
| 바닥 | 16×16 타일 (지역마다 한 벌: 아스팔트·승강장·마트 바닥·옥상) |
| 걷기 동작 | **4장** (팔 흔들기 + 몸 1점 들썩임), 달리는 좀비는 빠르게, 좀비는 비틀거림 |
| 방향 | **3방향**: 앞모습 · 뒷모습 · 옆모습(좌우 뒤집기) — v0.1부터 |
| 그 밖의 동작 | 서 있기 숨쉬기 2장, 공격(총구 불꽃·반동 / 근접 휘두르기 궤적), 맞으면 한 장면 하얗게 + 살짝 밀림, 쓰러지기 3장 |

## 밤 분위기 (시안의 핵심)
- 화면 전체를 어둡게 덮고, **생존자 주변(손전등)과 가로등 주변만 밝게**
- 가로등 빛은 살짝 따뜻한 노란색
- 도시: 도로(노란 점선 차선, 횡단보도) + 인도 블록 + 버려진 차·고깔·타이어·가로등

## 그림 만들기
- 시험판: 시안에서 찍은 그림을 그대로 씀 (코드에서 글자 지도로 그림 생성)
- 다듬을 때: 무료·상업 이용 가능(CC0 등) 픽셀 자료를 참고하거나 직접 다시 찍기. 출처는 `docs/출처.md`에 기록
- 기존 게임 캐릭터·그림을 닮게 만들지 않는다

## 사운드
- 효과음: 총소리, 맞는 소리, 조각 줍기, 레벨 업, 거대 변종 등장, 헬기 소리(4:30), 승리·패배
- 음악: 게임 중 1곡(긴장감 있는 8비트풍), 결과 화면 1곡
- 출처 후보: CC0 무료 효과음, 또는 8비트 효과음 생성 도구로 직접 만들기
- 폰 무음 모드·설정에서 끄기 지원

## AI 티 안 나게 (사용자 요청 2026-11-07)
"AI가 찍어 낸 것 같다"는 느낌은 **어디서 본 듯한 무난함 + 어긋난 디테일**에서 나온다. 아래를 단계마다 점검한다.

| AI 티 나는 것 | 우리는 이렇게 |
|---|---|
| AI 이미지 생성 그림 (손가락·글자 뭉개짐, 화풍 들쭉날쭉) | **AI 이미지 생성 안 씀.** 픽셀은 글자 지도로 한 점씩 정해서 만듦 → 팔레트·크기·테두리가 전부 같은 규칙 |
| 좌우가 똑같은 대칭 캐릭터, 딱딱한 자세 | 일부러 비대칭(한쪽 어깨 처짐, 찢어진 소매, 한쪽만 신발), 동작에 무게감(내딛을 때 1점 내려감) |
| 모든 움직임이 같은 속도로 일정함 | 동작마다 장면 길이를 다르게(내딛기 길게·떼기 짧게), 좀비마다 걸음 박자 조금씩 다르게 |
| "에픽", "전설의", "여정" 같은 뻔한 말, 번역투 | **동네 말투**: "편의점 앞으로 와!", "헬기 3분 남았다!", 아이템 설명에 한 줄 농담 |
| 어디 도시인지 모를 배경 | 한국 동네 디테일: 편의점, 치킨집 간판, 배달 오토바이, 분리수거함, 횡단보도 음성, 지하철 노선 색 |
| 이름 없는 적 | 좀비 옷차림에 이야기: 사원증 목에 건 직장인 좀비, 배달 가방 멘 좀비, 앞치마 두른 마트 직원 좀비 |
| 10·20·30처럼 딱 떨어지는 숫자만 | 밸런스 숫자는 해 보고 고친 값(예: 13, 26, 0.35초) |
| 효과음 하나를 계속 반복 | 같은 소리도 3~4개 중 무작위 + 높낮이 조금씩 다르게 |
| 이모지·영어 라벨·흔한 둥근 버튼 UI | 픽셀 글꼴, 각진 패널, 게임 안 물건 느낌(무전기 화면, 종이 지도)으로 UI를 꾸밈 |
| 너무 매끈한 그라데이션·빛 번짐 | 빛도 픽셀 단계로 끊어서(3~4단계 밝기) 그림 |

- 단계가 끝날 때마다 이 표로 "AI 티 점검"을 한 번 하고, 걸리는 건 다음 단계 전에 고친다.
- 한계(솔직히): 제 픽셀 그림은 깔끔하게 규칙적이지만, 사람 화가만큼 개성 있는 손맛은 부족할 수 있다. v0.8 연출 단계에서 무료 공개 픽셀 자료(CC0)를 참고해 다듬거나, 원하면 사람 손을 한 번 거치는 것도 방법.
