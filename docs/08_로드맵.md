# 8. 로드맵 (고도화판 — 2026-11-07)

> 시간은 **제(Claude) 작업 시간** 기준이다. 실제로는 사용자분이 해 보고 의견 주시는 간격이 더해진다.
> 단계마다 끝나면: ① 자동 플레이로 오류·성능 확인 → ② 화면 캡처 확인 → ③ 사용자분이 직접 해 보기 → ④ 의견 반영 → ⑤ [09_결정기록.md](09_결정기록.md)에 기록.
> 단계마다 [02 §12 고급 게임 품질 기준](02_게임플레이.md)으로 점검한다.

## 큰 그림
```
v0.1 시험판 ─ v0.2 손맛·소리 ─ v0.3 조합 ─ v0.4 위기 ─ v0.5 은신처
   (한 판)        (느낌)        (빌드)     (이벤트·보스)  (판 밖 성장)
                                                              │
v1.0 출시 ◀─ v0.9 다듬기 ◀─ v0.8 연출 ◀─ v0.7 다시 하기 ◀─ v0.6 지역
(웹+안드로이드)  (밸런스·성능)   (타이틀·음악)  (감염도·도전·도감)  (4곳)
```

## 지금 상황 (2026-11-07 오전) — 시중 게임 기본 요소 전부 (문서 14)
사용자 요구("시중 게임처럼 모든 요소 다 넣어라", "1라운드부터 어렵게·한 판 3분", "미친 듯이 재밌고 개성 넘치게, BGM 도 계속 바뀌게")로 로드맵 v0.2~v0.7 의 대부분을 한꺼번에 넣었다. 웹 https://web-interface.github.io/zombie-city/

**묶음 1 끝없는 밤**: 한 밤 3분 → 헬기 타면 다음 밤(밤마다 세짐·날씨·음악이 바뀜), 새 좀비 6종 + 금빛 정예, 보스 3종 × 기술 3개 + 분노 + 체력 줄, 포위·떼 돌진·들개 무리, 위험물(침·식칼·철근·웅덩이·예고 원/선), 연속 처치, 보물 상자(슬롯)·자석·폭탄·냉각 스프레이, 제자리 압박, 생존자 말풍선, 밤 분위기 5가지
**묶음 2 나만의 빌드**: 생존자별 카드 풀, 새 무기 13·장비 16·진화 19·빼 버리기·히든 스킬 4(금색 카드·컷인), 화려한 무기 연출
**묶음 3 또 하고 싶게**: 저장, 고철, 은신처 강화 10종, 감염도 0~10, 업적 40, 도감, 기록, 판 목표 3개, 오늘의 도전, 설정(소리·진동·흔들림), 새 타이틀·결과 화면(아까운 표시·바로 다시)
**난이도**: 개고수 기준 (고수 봇 첫째 밤 40~55%), 기본 체력 −35%, 좀비 체력 성장 0.09/초, 가만히 서 있으면 4초 만에 몰려옴
