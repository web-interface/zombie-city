# 8. 로드맵 (고도화판 — 2026-11-07)

> 시간은 **제(Claude) 작업 시간** 기준이다. 실제로는 사용자분이 해 보고 의견 주시는 간격이 더해진다.
> 단계마다 끝나면: ① 자동 플레이로 오류·성능 확인 → ② 화면 캡처 확인 → ③ 사용자분이 직접 해 보기 → ④ 의견 반영 → ⑤ [09_결정기록.md](09_결정기록.md)에 기록.
> 단계마다 [02 §12 고급 게임 품질 기준](02_게임플레이.md)으로 점검한다.

## 큰 그림
```
v0.1 시험판 ─ v0.2 손맛·소리 ─ v0.3 조합 ─ v0.4 위기 ─ v0.5 은신처
   (한 판)        (느낌)        (빌드)     (이벤트·보스)  (판 밖 성장)
                                                              │
v1.0 출시 ◀─ v0.9 다듬기 ◀─ v0.8 연출 ◀─ v0.7 다시 하기 ◀─ v0.6 지역
(웹+안드로이드)  (밸런스·성능)   (타이틀·음악)  (감염도·도전·도감)  (4곳)
```

**v0.1 에 들어간 것**
- 타이틀 → 생존자 고르기(4명, 전직 갈래 미리 보기) → 한 판(5분) → 결과
- 생존자 4명 × 시작 무기·특성·스킬, 무기 6종·장비 4종, 좀비 4종 + 도살자, 전직 12갈래 × 2단계(옷차림 16벌)
- 걷기 4장·3방향, 맞기·쓰러지기 동작, 밤 조명(손전등·가로등·빛과 어둠), 헬기 탈출(4:30 착륙 지점 → 5:00 헬기)

**뒤 단계에서 앞당겨 넣은 것** (밤사이 커뮤니티·디자인 조사 반영, 문서 13)
