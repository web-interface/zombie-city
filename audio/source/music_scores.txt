# [하는 일] 음악 악보 원본: 악기 소리 설정(@instrument·@drum)과 곡 4개(한 판 음악 3층 · 타이틀 · 결과 · 은신처)의 마디별 음표.
# [쓰는 곳] tools/build_sounds.py → tools/sound_music.py 가 읽어 tools/chiptune.py 로 audio/music_*.wav 를 만든다. 음악을 바꿀 때는 이 파일만 고치고 도구를 다시 돌린다.
# [근거 문서] 02 §12 위험할수록 악기가 더해지는 음악, 06 사운드, 14 §3 은신처
#
# 쓰는 법
#   @instrument 이름 설정…   선율 악기 (설정 = 키=값, 값이 여럿이면 쉼표. adsr=올라가기,줄기,유지 높이,놓기 · gate=음 길이 중 소리 내는 비율
#                            · vibrato=빠르기,깊이(반음),늦게 시작 · echo=늦는 칸 수,되풀이 비율,첫 메아리 크기 · pitch=정해진 높이(노이즈 악기))
#   @drum 이름 설정…         타악기 소리 한 겹. 같은 이름을 여러 줄 쓰면 겹쳐서 한 소리가 된다 (env=올라가기,버티기,줄어드는 세기)
#   @song 이름 bpm=빠르기 bars=마디 수 [peak_db=가장 큰 소리]  → 이 아래 @part 들이 한 곡. 같은 곡의 파일들은 길이·템포가 같다 (peak_db 기본 −3)
#   @part 파일이름 악기 [volume=세기]      → 그 다음 줄들이 마디들 ('|' 로 나눔)
#   음표: D5:3 = 레 5옥타브 3칸(16분음표 3개), 칸 수가 없으면 1칸.  . = 쉼  ~ = 앞 음 이어서  F4+A4 = 함께(화음)  % = 앞 마디 그대로
#   타악기 마디: 16글자, X = 세게, x = 보통, . = 쉼.   한 마디 = 16칸 (안 맞으면 도구가 몇 번째 마디인지 알려 준다)
