# fonts — 글꼴 폴더
게임에 쓰는 글꼴 파일과 사용 조건. 글꼴 파일에는 주석을 넣을 수 없어서 여기에 적는다 (문서 10 §5).

| 파일 | 무엇 | 쓰는 곳 | 출처 · 사용 조건 |
|---|---|---|---|
| `Galmuri11.ttf` | 한글 픽셀 글꼴 (12점에서 또렷) | 게임 화면 기본 글자 — 시간·레벨·카드 이름 (문서 06 글꼴) | Galmuri 2.40.3 (npm `galmuri`, 제작 Lee Minseo), SIL Open Font License 1.1 — 무료·상업 이용 가능 |
| `Galmuri11-Bold.ttf` | 위 글꼴 굵게 | 제목·강조 ("레벨 업!", "구조 성공!") | 위와 같음 |
| `Galmuri9.ttf` | 작은 한글 픽셀 글꼴 (10점) | 카드 설명·작은 글 | 위와 같음 |
| `Galmuri-LICENSE.txt` | Galmuri 사용 조건 원문 | 배포할 때 같이 넣음 | 위와 같음 |

- 픽셀 글꼴이라 Godot 가져오기 설정에서 **부드럽게 하기(안티에일리어싱)를 끈다** (문서 07).
- 처음 계획한 Pretendard 는 화면 글자를 전부 픽셀 글꼴로 통일하면서 뺐다 (2026-11-07, 문서 09).
